# Signa Index 文档信息图生成提示词套件（简体中文首版）

这套提示词用于生成 Signa Index 文档中的首批十张机制型信息图。它继承当前 Signa 前端的视觉语言，同时参考旧版 Doc 信息图的组织方式：明确标题、单一主题、清晰流程、功能性图标、必要箭头和一句结论。

## 一、使用方法

每一张图都单独生成，不要一次要求模型生成十张，也不要让模型自行延展内容。

每次生成时上传两张参考图：

1. **Image 1｜视觉基准**：`visual-system/signa-index-vis-board.png`
2. **Image 2｜结构参考**：每张任务所指定的旧版 Doc PNG

然后按顺序粘贴：

1. 下方的「统一母提示词」；
2. 对应编号的「单图任务提示词」；
3. 下方的「统一禁止项」。

推荐参数：

- 用途：文档内嵌信息图；
- 比例：横向 3:2，首选 `1536 × 1024`；如生成工具只支持常见宽屏，可用 16:9；
- 质量：高；
- 格式：PNG；
- 一次只生成一张；
- 第一轮先验证结构和文字，确认后再追求纹理细节；
- 最终需要在文档正文约 760px 宽度下仍能看清所有主标签。

> 旧版 Doc 图片只提供版式、层级和信息组织参考。不要复制它的英文文案、浅色背景、旧品牌配色或具体图形。

## 二、统一母提示词

将这一段放在每张单图任务之前。

```text
Use case: infographic-diagram
Asset type: Signa Index VitePress 文档内嵌机制信息图
Language: 简体中文

Input images:
- Image 1 是 Signa Index 当前 VIS board。它是颜色、字体气质、表面层级、边框、圆角、留白、数据强调方式和整体精致度的唯一视觉基准。
- Image 2 是旧版 Signa Doc 信息图。它只作为信息结构参考：借鉴清晰标题、模块分组、箭头关系、功能性图标和底部结论的做法；不要复制其英文文字、浅色背景、旧配色、人物造型或具体内容。

Primary request:
制作一张高完成度、可直接进入正式产品文档的 Signa Index 中文信息图。它必须首先准确解释一个机制，其次才是视觉表现。整体应像成熟金融基础设施或指数方法论文件中的编辑型信息图，不像广告海报，也不像概念艺术。

Scene/backdrop:
- 使用纯深海军蓝画布 #04101F。
- 内容模块使用 #08182A、#0B1C30、#0E2035 三档深色表面形成克制层级。
- 1px 边框使用 #24364E；关键边框可使用 #334862。
- 不使用白底，不使用大面积渐变，不使用发光背景或装饰纹理。

Style/medium:
- 精致、克制、编辑感强的矢量式金融信息图。
- 造型由清晰矩形模块、细线连接、准确箭头、少量功能性线性图标和紧凑数据标签构成。
- 模块圆角视觉上约 8–12px，边框细而稳定，阴影极弱或没有阴影。
- 画面应继承当前 Signa 产品界面的信息密度和交易产品气质，但不要绘制完整 App UI。

Typography:
- 中文主标题：清晰、沉稳，短标题可带温和的编辑型衬线气质；颜色 #F4EEE5。
- 正文和模块标签：现代中性 CJK 无衬线，颜色 #F5F7FB 或 #C3CAD6。
- 变量、权重、百分比、公式和事件编号：紧凑等宽字体，颜色按数据语义使用。
- 文字必须逐字准确、自然排版、无乱码、无错别字、无多余文案。
- 不要把任何重要说明做成极小脚注。

Color palette and semantic use:
- 画布：#04101F
- 主文字：#F5F7FB
- 标题暖白：#F4EEE5
- 次级文字：#C3CAD6
- 弱化文字：#8E9BB0
- 正向、有效状态、连续主线：#43E6A6 或 #3ADF91
- 反向或风险：#FF7585
- 转换、审查、生效、产品引用：#E1AD65
- 操作性警告：#F4B433
- 色彩必须承担信息含义，不能只是装饰。

Composition/framing:
- 横向 3:2 构图，完整画面，不裁切任何模块。
- 上方保留明确标题区，中部只解释一个主要机制，下方保留一句结论。
- 默认左到右阅读；只有计算、层级或矩阵主题才使用上到下结构。
- 每张图控制在 3–6 个主要模块；每个主模块最多一个功能性图标。
- 连接线不得穿过文字或模块，不得形成含糊交叉。
- 四周留出足够安全边距，缩小到文档正文宽度后仍然清楚。

Constraints:
- 只呈现单图任务中明确给出的信息和逐字文案。
- 所有指定文字都要逐字呈现；不增添标题、副标题、标签、日期、价格、百分比或营销口号。
- 关系、方向、正负号、权重和公式必须准确。
- 图标只能说明真实角色或步骤，不得制造额外概念。
- 不重绘、不变形、不伪造 Signa Logo；除非任务明确要求，否则图中不放 Logo。
- 无水印，无生成器签名，无假二维码。
```

## 三、统一禁止项

将这一段放在每张单图任务之后。

```text
Avoid:
- 抽象地球、世界地图、宇宙星球、粒子网络、神经网络、信号波、数据隧道；
- 金币、代币、硬币堆、K 线、蜡烛图、火箭、奖杯、盾牌堆叠；
- 机器人、机械大脑、AI 头像、人脸、人物插画、握手、团队合影；
- 漂浮玻璃卡片、霓虹发光、赛博朋克、夸张 3D、金属材质、玻璃拟态；
- 无信息价值的装饰图标、背景噪点、光晕、网格、波纹和箭头；
- 通用企业蓝白 PPT、白底信息图、彩虹配色、卡通风格；
- 未提供的真实市场数据、日期、指数名称、产品名称、收益率和概率；
- 英文替代中文、乱码、伪汉字、错别字、重复文字、多余脚注；
- 连接线穿过文字、元素相互遮挡、文字过小、边缘被裁切；
- 水印、署名、生成器标识、假 Logo、假 UI。
```
