# Construction process

Signa Index converts a changing set of event contracts into a consistently defined, reproducible, and time-continuous world-state index.

## Six stages

1. **Define the target state:** specify the persistent real-world direction to measure.
2. **Select event contracts:** identify contracts with a material causal link to that state.
3. **Align event direction:** map outcomes to state strengthening or weakening.
4. **Determine state exposure:** assess causal strength, information independence, and price quality.
5. **Aggregate state repricing:** calculate weighted, direction-adjusted price changes.
6. **Review and roll:** update components while preserving index continuity.

## Principles

### Causality first

Eligibility depends on whether the outcome can change the target state through a clear mechanism, not on keyword similarity.

### Direction consistency

Every component maps to the same state coordinate so that price changes share a consistent financial meaning.

### Exposure, not popularity

Weights measure effective exposure to the target state, not trading volume, media attention, or subjective importance alone.

### Continuous, not rigid

The target state and rules remain consistent while components update with event lives and information conditions.

### Explainable and reproducible

Every admission, direction, weight, and rule change should have a recordable basis.
