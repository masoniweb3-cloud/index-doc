# Review and rebalancing

Scheduled reviews update components and weights so that the event set continues to represent the target state without opaque ad hoc judgment.

## Scheduled review

Each index should disclose its review frequency and effective rules. A review typically:

- checks whether current components remain valid;
- removes settled, expiring, or irrelevant events;
- evaluates new candidates;
- updates information-overlap relationships;
- reassesses price quality and state exposure;
- normalizes weights for the next period.

## Effectiveness

Old components finish under current-period rules. New components and weights begin at the scheduled effective time.

Rebalancing itself should not create a return. The new basket inherits the pre-effective index level and begins from new price baselines.

## Extraordinary review

Rules may trigger an extraordinary review when a contract settles early or is voided, a data source fails for an extended period, settlement becomes materially disputed, prices lose usability, or the original causal path fails.

Extraordinary review preserves methodological validity; it is not discretionary market timing based on performance.

## Review records

Each review should preserve component changes, directions, weights, exclusions, effective time, and implementation version.
