# Component selection

Components come from observable, real event contracts. A candidate must have an explainable material causal link to the target state and meet minimum price-quality requirements.

## Inclusion criteria

- clear proposition, outcomes, and settlement time;
- stably accessible market prices;
- a clear impact path to the target state;
- consistently mappable direction;
- useful new information relative to current components;
- remaining maturity appropriate for the review cycle.

## Causal path

Each candidate should support a concise exposure statement:

> Event outcome → real-world mechanism → target-state change

If the mechanism cannot be explained beyond broad association, the event should not enter.

## Information overlap

Different contracts may repeat the same fact. Treating all as independent overstates one proposition. Reviews identify:

- different expiries for the same event;
- differently worded markets for the same outcome;
- contracts dependent on the same prerequisite;
- persistently similar prices with little new information.

Highly overlapping components can be selectively retained, combined, or down-weighted.

## Exclusions

Ambiguous propositions, unstable settlement rules, distorted prices, insufficient liquidity, or uncertain causal direction are grounds for exclusion. Topical relevance alone is not eligibility.
