# Target-state definition

The first step is not finding events; it is defining the **target state**.

The target state determines component boundaries, direction, weight meaning, and interpretation. Ambiguity compounds through every later step.

## Requirements

### State proposition

State the persistent direction in one sentence. Avoid broad themes that cannot be judged as strengthening or weakening.

### Long definition

Define which real-world changes strengthen the state through mechanisms, not only example events.

### Short definition

Define which changes weaken it and the logical relationship to strengthening.

### Time horizon

Specify the dominant horizon. Short shocks and structural change may point in different directions.

### Inclusion boundary

Define potentially valid event types and adjacent themes that remain excluded.

## Simplified example

For a peace-process state:

- Strengthening: the conflict system moves from escalation toward de-escalation, negotiation, ceasefire, and stable arrangements.
- Weakening: military escalation, failed talks, or breakdown of stable arrangements becomes more likely.
- Excluded: regional economic or domestic political events without a clear conflict mechanism.

## Definition freeze

The target state should be reviewed and versioned before launch. It must not be changed during operation merely to fit observed price performance.
