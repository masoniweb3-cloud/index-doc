# Long and short exposure

World states can strengthen or weaken. Signa provides long and short expressions for the same target state.

## Long exposure

The long index rises when markets collectively increase pricing toward a strengthening state. In a peace-process index, higher ceasefire and negotiation probabilities generally contribute positively, while higher escalation probability contributes negatively.

## Short exposure

The short index reverses the same component directions to express state weakening. This is a rules-based measurement of the other side of the same coordinate, not a value judgment about real events.

## Short is not selling or leveraged shorting

- Buying long shares holds the strengthening direction.
- Buying short shares holds the weakening direction.
- Selling only reduces shares already held.
- Selling beyond the position cannot create a naked short.
- Long and short are not YES/NO prices that must add to 100.

Their log changes are strictly opposite, but ordinary percentage returns do not add to zero after compounding. Position results also include the buy opening fee and depend on a valid sell quote.
