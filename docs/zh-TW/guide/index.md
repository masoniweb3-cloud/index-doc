# 開始使用 Signa Index

Signa Index 把同一現實主題下的多個預測市場合成為連續指數。在當前產品中，使用者可以用 USDT 買入某個主題的正向或反向指數份額，並在之後賣出已持有的份額。

## 使用前先知道這六件事

1. **當前使用 BNB Smart Chain（BSC）。** 充值和提現資產為 BSC 上的 USDT（BEP-20）。
2. **每個主題都有兩個方向。** 正向跟隨主題走勢，反向與主題反向變動。
3. **買入是建立持倉，賣出是減少持倉。** 賣出不會自動建立反向倉位；要表達相反觀點，需要買入反向指數。
4. **當前 1% 是買入開倉費。** 它不是“盈利稅”，也不是賣出手續費；當前賣出不收平倉費。
5. **指數份額不是錢包代幣。** 份額記錄在你的 Signa 帳戶中，不能轉給其他使用者；需要先賣出換回 USDT，才能提現到錢包。
6. **充值後由 Signa 托管資金。** 專屬地址用於識別充值，確認後的 USDT 通過多重校驗和可對賬帳本統一管理；這不是全程自托管模式。

## 一次完整流程

### 1. 登入並準備資金

連接支持 BSC 的錢包並完成簽名登入。從當前錢包充值時，還需要少量 BNB 支付鏈上 Gas 費。

### 2. 充值 BSC USDT

打開“充值”，可以直接從已連接錢包發送，也可複製系統為你分配的專屬 BSC 充值地址。交易達到所需確認數後，USDT 會記入可用交易餘額。

### 3. 選擇主題和方向

從[六個首發指數](/zh-TW/indexes/)中選擇主題，判斷它所描述的現實狀態會增強還是減弱，再選擇正向或反向指數。兩個方向都有自己的指數點位，不是必須相加等於 100 的 YES/NO 價格。

### 4. 獲取報價並確認買入

輸入 USDT 金額後，系統會顯示指數參考點位、預計份額、開倉費和總支付金額。服務端報價只在倒計時內有效，超時後需要刷新。

### 5. 查看持倉或賣出

成交後，可在“持倉”查看份額、平均買入價、當前價值和未實現盈虧。賣出時只能減少當前帳戶已有的份額。

### 6. 提現

賣出後的可用 USDT 可申請提現至當前登入錢包。提現前需要再次簽名確認金額、手續費和目標地址。

::: tip 查看當前產品
指數點位、實時成分、費率、限額和交易可用性，以 [Signa 官網](https://signaindex.com/) 產品頁面及訂單確認頁為準。
:::
