# 充值與提現

Signa 當前使用 **BNB Smart Chain（BSC，Chain ID 56）** 上的 **USDT（BEP-20）** 處理使用者充值和提現。

::: info 資金如何保管
每個帳戶使用專屬 BSC 地址識別充值。系統校驗網路、USDT 合約、收款地址、金額和區塊確認後，才會將資金記入你的可用餘額。入賬後的 USDT 由 Signa 托管，並通過分離的充提控制、多重校驗和可對賬帳本進行管理。提現僅發送至與帳戶對應的 BSC 錢包，並需要錢包再次簽名確認。
:::

::: danger 不要跳過這一條
只能向充值地址發送頁面指定的 BSC USDT。發送其他代幣，或從 Ethereum、Polygon、Tron 等其他網路發送，都可能造成永久損失。
:::

## 如何充值

1. 登入後打開“充值”。
2. 核對網路為 **BNB Smart Chain（BEP-20）**，並核對頁面顯示的 USDT 代幣合約。
3. 選擇一種方式：
   - 在頁面輸入金額，直接調起當前連接錢包；
   - 複製或掃描系統為你分配的專屬 BSC 充值地址，再從其他錢包轉入。
4. 確認金額不低於頁面顯示的“最低充值”。
5. 發起交易後，等待狀態從“已提交”、“已檢測”變為“已入賬”。

從已連接錢包充值時，錢包還會顯示一筆 BNB Gas 費。這筆費用支付給 BSC 網路，不是 Signa 的 1% 開倉費。

### 低於最低充值會怎樣？

當前系統會記錄低於最低額的鏈上轉賬，但不會將其記入交易餘額，也不承諾自動找回。最低金額可能調整，以充值頁面的當前值為準。

## 什麼時候入賬？

錢包顯示“已發送”不等於 Signa 已入賬。系統需要：

1. 在 BSC 上檢測到正確的 USDT Transfer；
2. 核對收款地址、代幣合約和金額；
3. 等待頁面顯示的所需確認數；
4. 將資金記入你的可用交易餘額。

充值記錄會顯示交易哈希、確認進度和最終狀態。

## 如何提現

1. 打開“提現”，確認可提現餘額。
2. 輸入金額，頁面會顯示最低額、單筆上限、UTC 每日上限、手續費和預計到賬金額。
3. 確認目標地址。當前提現只會發回與登入帳戶對應的 BSC 錢包。
4. 在錢包中籤署提現授權。簽名用於確認金額、手續費、目標地址和一次性隨機數，不會把私鑰交給 Signa。
5. 提交後在“最近提現”中查看處理中、已提交 BSC 或已完成等狀態。

## 處理中的提現

申請提交後，對應金額會先從可用餘額中預留。只有在系統確認提現尚未發送，或鏈上已經確認最終失敗後，預留金額才會返回可用餘額。

網路超時、鏈上廣播結果不明確或已經產生交易哈希時，提現會保持處理中，直到系統確認最終結果。在此期間不要重複提交；過早返還預留金額可能造成同一筆資金被重複支付。

## 如何理解頁面狀態？

### 充值狀態

- **已提交**：錢包已經發出交易，Signa 正在等待鏈上記錄；
- **已檢測**：系統已經識別正確轉賬，仍在等待所需確認；
- **已入賬**：資金已經記入 Signa 可用餘額，可以用於交易。

### 提現狀態

- **處理中**：金額已經預留，系統正在校驗或準備鏈上發送；
- **已提交 BSC**：交易已經發送至 BSC，正在等待最終確認；
- **已完成**：鏈上轉賬已確認，提現流程結束。

如果狀態長時間沒有變化，請查看[充提問題排查](/zh-TW/guide/troubleshooting)，並保留錢包地址和交易哈希供核查。

::: tip 數值以頁面為準
最低充值、提現限額、提現手續費和所需確認數都可能更新。提交任何資金操作前，以 Signa 產品頁面實時顯示的規則為準。
:::
