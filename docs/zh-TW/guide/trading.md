# 如何交易

Signa 的交易對象是記錄在使用者帳戶中的指數份額。買入時，你用 USDT 建立某個主題、某個方向的持倉；賣出時，你把已有份額按當前報價換回 USDT。

::: info 指數份額不是鏈上代幣
指數份額不會發送到你的錢包，目前不能轉給其他使用者，也不能作為指數份額直接提現。退出持倉時，需要先賣出份額換回 USDT，再提現可用 USDT。
:::

## 先選主題，再選方向

每個主題都提供兩個獨立方向：

| 你的判斷 | 選擇 | 典型表現 |
| --- | --- | --- |
| 目標狀態將增強 | 正向指數 | 成分市場更支持該主題時上升 |
| 目標狀態將減弱 | 反向指數 | 成分市場更不支持該主題時上升 |

例如，對“和平進程”主題，如果你認為停火、談判等事件的整體定價會越來越有利於和平狀態，可選正向；如果認為該狀態會減弱，可選反向。

::: info 反向不等於“賣出”
“賣出”只是減少你已經持有的份額。如果你沒有持倉，不能通過點擊賣出建立空頭。要獲得相反方向的價格暴露，應買入對應的反向指數。
:::

## 買入步驟

1. 打開一個主題，選擇正向或反向。
2. 在交易面板選擇“買入”，輸入投入的 USDT 本金。
3. 查看預估份額、指數參考點位、開倉費和總支付金額。
4. 獲取服務端報價。報價會同時鎖定指數價格、開倉費、指數版本和有效期。
5. 在倒計時內確認訂單。報價過期後，需要重新獲取。
6. 成交後在“持倉”和“記錄”查看份額與訂單回執。

## 賣出步驟

1. 在交易面板選擇“賣出”，或從“持倉”中打開快捷賣出。
2. 選擇要減少的持倉，輸入份額，也可選擇 25%、50% 或全部賣出。
3. 查看賣出總額、平倉費和預計收到的 USDT。頁面顯示的是當前可獲得的產品報價，不是對未來退出價格的保證。
4. 獲取並在有效期內確認服務端報價。
5. 成交後，已賣份額從持倉中減少，USDT 記入可用餘額。

當前只能賣出登入帳戶真實持有的份額，不允許超額賣出。

## 為什麼有時不能交易？

遇到以下情況時，系統會暫停新報價或訂單：

- 最新指數價格不可用或過時；
- 交易、訂單路由或交易後處理系統未就緒；
- 交易安全條件不滿足，系統暫時關閉新訂單；
- 訂單金額低於最低額、超過最高額，或買入總額超過可用 USDT；
- 賣出份額超過當前持倉。

這種情況下，已有持倉和歷史訂單仍可查看。不可用的指數價格不會被當作 0 處理。

## 報價和指數點位有什麼區別？

指數點位用於記錄主題狀態變化，本身不是一枚以 USDT 計價的鏈上代幣。產品使用當前指數參考點位計算買入份額和賣出金額，並生成有有效期的服務端報價。

只有訂單確認頁中的有效報價可以用於成交。頁面上的歷史點位、走勢圖或已經過期的報價，都不代表使用者一定能夠按該數值買入或賣出。
