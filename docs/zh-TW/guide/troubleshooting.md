# 充提問題排查

充值或提現長時間沒有完成時，先不要重複發送資金或重複提交申請。鏈上確認、網路擁堵和狀態同步都可能需要時間，重複操作反而可能讓問題更難核對。

## 充值沒有入賬

依次檢查：

1. 轉賬網路是否為 **BNB Smart Chain（BSC，Chain ID 56）**；
2. 發送的資產是否為充值頁指定的 **USDT（BEP-20）**；
3. 收款地址是否與當前帳戶的專屬充值地址完全一致；
4. 金額是否達到頁面顯示的最低充值額；
5. 區塊鏈瀏覽器是否已經顯示交易成功；
6. 頁面是否仍在等待所需確認數。

低於最低額、發錯網路、發錯代幣或發往錯誤地址的轉賬，不承諾能夠自動找回。

## 提現一直處理中

“處理中”表示對應金額已經從可用餘額中預留，但鏈上最終結果尚未確定。此時：

- 不要重複提交同一筆提現；
- 不要只根據錢包通知判斷成功或失敗；
- 如果頁面已經顯示交易哈希，可在 BSC 區塊鏈瀏覽器查看確認進度；
- 網路超時或廣播狀態不明確時，餘額不會立即退回，以避免重複支付。

只有系統確認交易尚未發送，或鏈上已經確認最終失敗後，預留金額才會退回可用餘額。

## 請求核查時準備什麼？

通過 Signa 官網公佈的官方支持渠道請求核查時，請提供：

- 登入錢包地址；
- BSC 交易哈希；
- 充值或提現金額；
- 大致發起時間和時區；
- 頁面顯示的當前狀態；
- 必要時附上不包含敏感資訊的頁面截圖。

::: danger 永遠不要提供這些資訊
Signa 不會要求你提交私鑰、助記詞、錢包密碼或遠程控制設備。任何索要這些資訊的人都不應被信任。
:::
