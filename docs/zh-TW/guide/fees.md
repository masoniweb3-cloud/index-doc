# 費用說明

| 操作 | 當前費用 | 由誰收取 |
| --- | ---: | --- |
| 充值 | Signa 不收充值費 | 從錢包轉賬時，BSC 網路收取 BNB Gas 費 |
| 買入 | 本金的 1% | Signa 開倉費 |
| 賣出 | 0% | 當前不收平倉費 |
| 提現 | 以提現頁顯示為準 | 從提現總額中扣除 |

## 1% 到底是什麼？

當前產品的 **1% 是買入開倉費**。它在使用者買入並創建指數份額時收取，與用於計算份額的本金分開列示。

它不是：

- 不是根據盈利收取的“收益稅”；
- 不是充值的 BSC Gas 費；
- 不是提現手續費；
- 不會直接改變指數點位。

### 買入示例

假設使用者輸入 **100 USDT** 作為買入本金，開倉費率為 1%：

| 項目 | 金額 |
| --- | ---: |
| 用於計算指數份額的本金 | 100 USDT |
| 1% 開倉費 | 1 USDT |
| 總支付 | 101 USDT |

帳戶可用餘額至少需要覆蓋總支付金額，而不只是買入本金。

## 賣出收費嗎？

按當前產品規則：

- 開倉費只在買入時收取；
- 賣出的平倉費為 **0%**；
- 賣出報價顯示的賣出總額，就是當前規則下預計記入可用餘額的金額。

歷史訂單會保留成交當時的實際費用記錄，不會因後續規則變更而重寫。

## 還有哪些費用？

### BSC Gas 費

從已連接錢包向專屬充值地址發送 USDT 時，錢包需要支付 BNB Gas 費。該費用由 BSC 網路收取，金額隨網路狀態變化。

### 提現手續費

提現可以設置固定手續費。頁面會在簽名前顯示：

- 帳戶扣減總額；
- 提現手續費；
- 錢包預計到賬額。

提現金額必須高於手續費。具體費用以提現頁的當前策略為準。

::: warning 報價是最終確認依據
費率和產品規則可能調整。每次買入、賣出或提現前，都應以確認頁顯示的費率、實際金額和有效期為準。
:::
