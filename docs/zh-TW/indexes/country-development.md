# 國家發展類指數

國家發展類指數衡量一個國家或經濟體的長期發展狀態如何被相關事件持續重定價。

它關注的不是單一經濟資料，也不是對國家整體價值作主觀評分，而是市場對一組明確發展機制的方向性判斷。

## 可能的狀態維度

- 經濟增長與生產能力；
- 制度執行和政策連續性；
- 產業升級與關鍵基礎設施；
- 外部融資、貿易與市場准入；
- 人力資本和技術吸收能力。

具體指數應選擇一個足夠明確的目標狀態，而不是把所有維度無差別合併。

## 候選事件示例

可能相關的事件包括重大政策通過、國際組織安排、關鍵基礎設施交付、貿易限制變化或具有結構性影響的產業里程碑。

事件只有在能形成清晰的“結果—機制—發展狀態”路徑時才具備候選資格。

## 主要邊界

短期市場情緒、孤立的政治新聞或與發展機制缺乏直接聯繫的事件，不應僅因發生在同一國家就被納入。

不同國家的指數也不能直接假設使用相同事件類型和權重，因為制度結構、經濟基礎與外部約束可能不同。

> 本頁描述指數家族框架，不代表某個國家發展指數已經正式發佈。
