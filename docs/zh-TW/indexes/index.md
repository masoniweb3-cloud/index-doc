# 首發指數

Signa Index 初版圍繞六個現實主題構建指數。每個主題都有正向和反向兩個獨立方向：正向用於表達主題狀態增強，反向用於表達主題狀態減弱。

下面的事件僅用於幫助理解方向，不代表當前實時成分。實際點位、成分和交易狀態以 Signa 產品頁面為準。

| 指數 | 正向指數通常在什麼情況下上漲 | 反向指數通常在什麼情況下上漲 |
| --- | --- | --- |
| **中東和平指數** | 停火持續、談判推進、人質釋放、外交正常化或衝突降級 | 戰爭延續、軍事升級、談判失敗或衝突擴散 |
| **中國國運指數** | 經濟韌性、科技能力、國際影響力、政策穩定性或外部安全改善 | 上述維度出現明顯惡化或重大外部壓力 |
| **美國國運指數** | 經濟韌性、科技領導力、制度運行、政策執行或國際影響力改善 | 衰退風險、制度衝突、科技領導力或國際影響力減弱 |
| **歐洲國運指數** | 經濟與貨幣韌性、能源安全、產業競爭力、一體化或國際影響力改善 | 經濟、能源、產業、一體化或外部安全環境惡化 |
| **AI 發展指數** | 模型能力、算力、產業落地、投資或有利於發展的治理環境進步 | 能力進展停滯、算力受限、投資收縮、落地受挫或監管顯著收緊 |
| **加密貨幣發展指數** | 採用擴大、監管更明確、機構參與增加、基礎設施成熟或主流金融整合 | 採用萎縮、監管打壓、機構退出或重大安全與信任危機 |

::: info 如何理解這些例子
指數不會因為出現一條相關新聞就機械上漲或下跌。事件必須進入當前成分，並經過方向映射和權重計算，其市場價格變化才會影響指數。
:::

## 不是 YES 與 NO

正向和反向指數不是一份二元合約的 YES 與 NO。兩者各自擁有連續點位，不要求相加等於 100。選擇反向指數也不是“賣出正向指數”，而是買入同一主題的另一種方向持倉。

## 查看與交易

具體指數的當前點位、正向/反向方向、實時成分、報價和可用狀態，以 [Signa 官網](https://signaindex.com/) 展示為準。

想瞭解指數為何會持續更新，可閱讀[到期與滾動接續](/zh-TW/methodology/rolling)；想瞭解買賣方式，可閱讀[如何交易](/zh-TW/guide/trading)。
