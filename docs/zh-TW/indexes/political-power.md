# 政治權力類指數

政治權力類指數衡量一個政治主體獲得、維持、轉移或失去制度性權力的狀態變化。

政治權力並不等同於知名度、民意熱度或單次選舉勝率。目標狀態必須說明所衡量的是哪種權力、在哪個制度範圍內以及通過什麼機制實現。

## 可能的狀態維度

- 贏得或維持行政權；
- 獲得立法控制能力；
- 形成穩定執政聯盟；
- 推進關鍵任命或政策議程；
- 在黨內或制度內維持領導地位。

## 候選事件示例

選舉結果、議會席位、聯盟組建、關鍵任命、彈劾或罷免程序，以及改變制度性控制能力的司法裁決，都可能形成有效暴露。

## 避免重複計權

政治市場中經常存在大量高度相關的命題，例如同一選舉的不同候選人市場、黨派控制市場和州級結果市場。

指數必須識別共同前置條件，避免對同一政治結果進行多次完整計權。

> 本頁描述指數家族框架，不代表具體政治權力指數已經正式發佈。
