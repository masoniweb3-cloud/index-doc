# 地緣秩序類指數

地緣秩序類指數衡量國家、聯盟和非國家主體之間的衝突、合作與穩定安排如何共同塑造持續性國際狀態。

## 可能的目標狀態

- 特定地區的和平進程；
- 聯盟體系的凝聚或弱化；
- 制裁與經濟隔離程度；
- 外交談判和安全安排的穩定性；
- 衝突升級或降級方向。

每個指數必須選擇單一、方向明確的目標狀態。例如，“地區和平進程”與“某聯盟影響力”屬於不同狀態，不應在沒有明確方法的情況下混合。

## 候選事件示例

停火、談判、軍事行動、條約批准、制裁變化和第三方安全承諾，都可能形成狀態暴露。

同一個事件對不同目標狀態可能具有不同方向和暴露。例如，一項軍事部署可能增強聯盟凝聚，卻減弱地區和平狀態。

## 主要風險

地緣事件高度依賴背景，且容易出現突發跳變、資訊不完整和多重因果。指數需要更嚴格的方向一致性、來源驗證和異常事件規則。

> 本頁描述指數家族框架，不代表具體地緣秩序指數已經正式發佈。
