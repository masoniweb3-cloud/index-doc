# 什麼是 Signa Index？

**Signa Index 把多個圍繞同一現實主題的預測市場，合成為一條持續更新的指數。**

比如，要判斷一個地區的和平進程是在改善還是惡化，只看“是否會簽署停火協議”這一份預測市場並不夠。談判是否重啓、軍事行動是否升級、制裁是否解除、第三方調解是否取得進展，都會影響和平進程。

這些事件各自回答一個具體問題。Signa Index 將它們放到同一個方向上，形成一條能夠持續反映和平進程變化的指數。

如果股票指數用多家公司的股價描述一組公司的整體表現，那麼 Signa Index 用多個事件合約的價格，描述一個現實狀態的整體變化。

## 什麼是“世界狀態”？

世界狀態，是無法由一個事件完整描述、但會被一系列事件共同推動的長期現實方向。例如：

- 一個國家的發展勢能是在增強還是減弱；
- 一個地區的地緣局勢是在緩和還是惡化；
- 一項技術是在加速普及還是失去動力；
- 一個政治力量是在擴大還是收縮。

單個事件會發生、結束和結算，但這些狀態仍會繼續變化。

## Signa 怎麼把事件變成指數？

Signa 會完成四件事：

1. 找出真正會影響目標狀態的事件；
2. 判斷事件結果代表狀態增強還是減弱；
3. 根據事件的重要性和市場品質分配權重；
4. 在舊事件結束後接入新事件，保持指數連續。

因此，Signa Index 不是事件概率的簡單平均，而是市場對一個長期現實方向的持續重新定價。

## 你看到的“指數”和買到的“份額”有什麼區別？

在 Signa 中，需要區分三個層次：

1. **事件合約**：預測市場中的具體問題，為某個結果形成市場價格；
2. **Signa 指數**：聚合多份事件合約，持續計算一個現實主題的正向或反向點位；
3. **指數份額**：Signa 根據指數點位提供報價、記錄在使用者帳戶中的交易持倉。

使用者買賣的是第三層的指數份額，不是直接買入某一份預測市場合約。指數份額也不是發送到錢包裡的 BEP-20 代幣，目前不能轉給其他使用者或直接從鏈上提現。退出持倉時，需要先把份額賣出換回 USDT，再將可用 USDT 提現到登入錢包。

指數點位本身不是概率，也不是天然以 USDT 計價的代幣價格。實際可以買到多少份、賣出可獲得多少 USDT，以產品在報價有效期內給出的確認結果為準。

## 正式定義

> 世界狀態指數是一類以事件合約價格為定價基礎，通過世界狀態映射、方向統一、狀態暴露加權與連續滾動，將多個離散事件合成為長期現實狀態敞口的規則型合成指數。
