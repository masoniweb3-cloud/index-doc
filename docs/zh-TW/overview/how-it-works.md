# Signa Index 如何運作？

Signa Index 的工作，可以概括為一句話：先說清楚要觀察什麼，再把真正相關的事件放到同一個方向上，最後將它們合成為一條連續指數。

下面繼續用“和平進程指數”作為例子。

![世界狀態指數從目標定義、事件選擇、方向統一和暴露加權，到價格聚合與滾動接續的六步構造流程](/images/en/03-index-construction-flow-en.png)

## 1. 先說清楚要觀察什麼

“和平”這個詞太寬泛。指數必須先明確：它觀察的是衝突體系從升級走向降級、談判恢復和穩定安排逐步形成的過程。

同時還要寫清楚什麼代表改善、什麼代表惡化。這個定義是後續所有事件判斷的共同標準，在指數構建中稱為**目標狀態**。

## 2. 找到真正會影響它的事件

接下來，從預測市場中尋找可能改變和平進程的事件，例如停火、談判、軍事升級、制裁變化和第三方調解。

每個候選事件都必須回答一個問題：

> 這個事件的結果，將通過什麼路徑改變目標狀態？

僅僅出現相似關鍵詞，或者最近很熱門，並不足以進入指數。必須能說明它為什麼會讓和平進程改善或惡化。

## 3. 把相反的事件放到同一方向

不同合約的價格上漲，可能代表完全相反的含義：

- 停火概率上漲，通常代表和平進程改善；
- 軍事升級概率上漲，通常代表和平進程惡化。

Signa 會把這些事件轉換到統一坐標：有利於目標狀態的變化記為正向，不利於目標狀態的變化記為反向。這樣，不同文字方向的市場價格才可以共同計算。

## 4. 判斷每個事件有多重要

一份覆蓋核心停火協議的市場，通常比一場象徵性會面的市場更能改變和平進程；一個交易連續、價格可信的市場，也比長期無人參與的市場提供更多有效資訊。

因此，Signa 不會讓所有事件平均分配影響力，而是綜合判斷：

- 事件對目標狀態的影響是否直接且重要；
- 它是否提供了新的資訊，而不是重複其他事件；
- 市場價格是否連續、可觀察且具有足夠品質。

這些判斷形成事件的**狀態暴露權重**。

## 5. 合成指數變化

指數聚合所有事件經過方向調整和權重處理後的價格變化。

當多個重要市場共同指向和平進程改善時，指數上升；當市場開始提高對衝突升級的定價時，指數下降。

指數關注的是市場判斷發生了怎樣的變化，而不是把各事件當前的概率直接求平均。

## 6. 舊事件結束後，換入新事件

停火談判會結束，新的談判和新的衝突事件還會出現。Signa 會在審查時點移除已經結算、即將到期或失去代表性的事件，再按照同一標準納入新的事件。

新組合從原有指數點位繼續計算，不會因為換了一批事件就重新從零開始。這個過程稱為**滾動接續**。

## 最終得到什麼？

最終結果不是“某件事會不會發生”的單一概率，而是一條持續反映市場如何重新判斷某個現實狀態的指數曲線。

> 事件可以結算，狀態持續存在；成分不斷變化，指數保持連續。
