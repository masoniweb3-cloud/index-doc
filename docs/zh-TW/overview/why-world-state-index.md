# 為什麼需要世界狀態指數？

預測市場擅長回答具體問題：某項法案會不會通過、某次談判會不會達成協議、某個產品會不會按時發佈。

但人們真正關心的，往往不是某一個事件，而是事件背後的長期變化。

| 單個事件回答的問題 | 人們真正想瞭解的狀態 |
| --- | --- |
| 停火協議會不會簽署？ | 和平進程是在改善還是惡化？ |
| 某項關鍵法案會不會通過？ | 一個國家的發展勢能是否增強？ |
| 某個產品會不會按時發佈？ | 一項技術是否正在加速普及？ |
| 某位候選人會不會贏得選舉？ | 一個政治力量是否正在擴大？ |

單個市場能給事件定價，卻很難獨自回答右邊這些問題。

## 單個事件只是一塊拼圖

和平進程不會由一次停火決定，技術普及也不會由一次產品發佈決定。重要的現實趨勢通常同時受到許多事件影響，每個事件只揭示其中一部分。

如果只看一個市場，讀者很容易把局部變化誤認為整體趨勢。

## 狀態不會隨一份合約到期

事件合約有明確的截止時間。結果確定後，市場結算並結束。

但和平進程、國家發展和技術演進不會因為一份合約結算就停止。新的談判、新的政策和新的里程碑會繼續出現。

這就產生了一個期限錯配：用會到期的事件市場，觀察不會到期的現實趨勢。

## 不同事件的“上漲”含義可能相反

“停火概率上升”通常意味著和平進程改善；“軍事升級概率上升”卻意味著和平進程惡化。雖然兩份合約的價格都在上漲，它們對同一狀態的含義正好相反。

因此，相關市場不能直接放在一起求平均。必須先統一方向，再判斷每個事件對目標狀態有多重要。

## Signa Index 解決的問題

Signa Index 把這些分散、短期、方向不一的事件信號組織起來：

- 找出真正會影響目標狀態的事件；
- 把正向和反向事件轉換到同一方向；
- 讓影響更直接、資訊品質更高的事件佔更大權重；
- 在舊事件結束後接入新事件，讓指數繼續運行。

最終得到的不再是一個孤立事件的概率，而是一條持續記錄現實狀態變化的指數曲線。

## 它帶來了什麼？

研究者可以觀察市場對長期趨勢的判斷如何變化，指數產品可以引用同一套公開規則，使用者也可以圍繞同一狀態表達正向或反向觀點。

預測市場為一個個事件定價；Signa Index 把這些事件組織成一條現實趨勢。
