# 事件合約

**一般大家所說的“預測市場”，在 Signa Index 的方法裡，就是一份事件合約。**

日常說“某件事開了一個預測市場”，通常指的是：圍繞一個具體問題，讓參與者買賣不同結果，並在答案確定後結算。

例如：

> 某國會在今年年底前降息嗎？

這個市場可以有 YES 和 NO 兩個結果。參與者的買賣形成市場價格；到年底後，再按照事先寫明的規則確定結果並完成結算。

在 Signa Index 的文檔裡，我們把這樣一個**有明確問題、有市場價格、也會到期結算的具體市場單元**稱為事件合約（Event Contract）。

## 為什麼使用“事件合約”這個名稱？

“預測市場”有時指整個產品或平台，也可能指某一個具體問題。為了在指數計算中說得更準確，Signa 使用“事件合約”指代一份具體、可被納入指數的市場。

一個事件合約對應一個有限問題；一個 Signa Index 則可能同時使用許多事件合約，共同描述一個長期現實狀態。

## 事件合約提供什麼資訊？

事件合約的價格反映參與者當前如何為某個結果定價。YES 價格上漲，通常表示市場正在提高對該結果的判斷；價格下降，則表示市場正在降低這一判斷。

Signa Index 使用這種真實市場中可觀察的價格變化，而不是由模型獨立生成一個概率。

在指數中，事件合約是價格輸入，不是指數最終要表達的長期狀態。

## 合格事件合約的基本條件

進入指數候選池的合約通常應具備：

- 清晰且可驗證的命題；
- 明確的 YES、NO 或其他結果定義；
- 公開的結算依據與截止時間；
- 可持續獲得的市場價格；
- 足以支持指數計算的價格品質；
- 與目標狀態之間可解釋的因果聯繫。

## YES 不等於正向

YES 只表示“問題中的命題成立”，不一定代表指數要觀察的狀態變好。

例如，“衝突是否升級”的 YES 價格上升，可能意味著“和平進程”狀態減弱。因此，事件合約必須先經過狀態方向映射，才能與其他成分共同計算。

## 到期與結算

事件合約具有有限生命週期。合約結算後不再提供新的價格變化，但其所反映的世界狀態可能仍在繼續。

Signa 通過固定審查和滾動接續更新事件集合，從而將短期合約轉換為長期狀態序列。
