# 世界狀態

<strong>世界狀態（World State）</strong>是由一系列現實事件共同揭示、跨越單一事件生命週期並持續變化的現實方向。

它不是抽象主題，也不是一組新聞標籤。一個合格的世界狀態必須滿足三個條件：

- **持續性**：狀態不會因某一份事件合約結算而終止；
- **方向性**：可以明確判斷狀態正在增強還是減弱；
- **經濟意義**：狀態變化能夠形成可解釋的風險、機會或決策價值。

## 狀態與事件的區別

事件是有限命題，狀態是長期坐標。

![短期事件合約會分別到期，長期世界狀態則持續存在](/images/en/02-event-vs-state-en.png)

“雙方是否在某日前簽署停火協議”是事件；“衝突體系是否由升級轉向降級”是狀態。前者可以結算，後者會繼續受到後續談判、軍事行動和政治安排影響。

## 狀態因子

多個事件的市場價格變化可能包含一個共同方向。Signa Index 將這一共同方向視為**狀態因子**。

它的作用類似於傳統金融中從一組證券收益中識別共同風險因子，但其資訊來源不是企業現金流或宏觀價格，而是事件結果及事件對現實狀態的因果含義。

## 目標狀態定義

每個指數都需要一份明確的目標狀態說明，至少包括：

1. 狀態名稱與經濟含義；
2. 狀態增強和減弱的判斷標準；
3. 可接受的事件影響路徑；
4. 明確排除的相鄰主題；
5. 適用時間範圍與審查頻率。

這份定義是成分選擇、方向映射和指數計算的共同依據。
