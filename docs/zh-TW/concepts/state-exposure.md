# 狀態暴露

<strong>狀態暴露（State Exposure）</strong>表示事件結果對目標狀態產生影響的有效程度。

它回答的不是“事件有多熱門”，而是“事件價格變化中有多少資訊真正屬於目標狀態”。

## 暴露的組成

狀態暴露主要由三個維度構成：

- **因果強度**：事件結果與目標狀態之間的影響是否直接、明確且重要；
- **資訊獨立性**：事件是否提供新的狀態資訊，而不是重複已有成分；
- **價格品質**：市場價格是否具有足夠的可觀察性、連續性和可靠性。

## 暴露與概率不同

事件發生概率高，不代表狀態暴露一定高。

一個幾乎確定會發生但對目標狀態影響很小的事件，可能只有較低暴露；一個發生概率較低但一旦發生會顯著改變目標狀態的事件，則可能具有較高暴露。

## 暴露與權重

指數把各成分的狀態暴露轉換為歸一化權重。權重決定每個事件的價格變化對當期指數變化貢獻多少。

狀態暴露是經濟含義，權重是計算表達。兩者相關，但不能混為一談。

## 動態變化

事件的有效暴露可能隨時間變化，例如剩餘期限縮短、價格品質下降、資訊被其他事件吸收或事件已經失去現實影響。

這類變化應在預設審查時點進入權重更新，而不應通過任意的盤中調整改變指數。
