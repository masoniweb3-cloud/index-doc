# 連續指數

單一事件合約會在結算後終止，世界狀態卻會持續演進。**連續指數**通過保持目標狀態和計算規則的一致，將不斷變化的事件集合連接為一條連續價格序列。

## 連續性的來源

Signa Index 的連續性不依賴永久不變的成分，而來自三個穩定要素：

1. 目標狀態定義保持一致；
2. 方向、權重和計算規則保持一致；
3. 成分更換從既有指數點位接續。

## 成分變化不是狀態收益

在審查時點加入或移除事件，只是更新用於觀察狀態的工具集合，不應被當作目標狀態本身發生了變化。

因此，新成分從新的有效週期開始貢獻價格變化，成分替換本身不製造指數跳變。

## 可比較性

連續序列使使用者能夠觀察：

- 某個狀態在不同時間的方向變化；
- 市場重定價的速度與幅度；
- 不同狀態指數之間的相對表現；
- 與現實事件時間線之間的關係。

## 連續不代表無變化

指數方法可以更新，但任何影響歷史可比性的變更都需要記錄、生效日期和版本說明。重大方法變化可能需要新指數版本，而不是直接改寫歷史序列。
