# 產品規則與聲明

本文件說明 Signa Index 文檔、指數資料和當前指數份額產品的一般使用邊界。具體參與資格、訂單和資金操作還受產品頁面展示的適用規則約束。

## 資訊性質

文檔用於解釋世界狀態指數、六個首發主題、交易方式和使用邊界。首發指數頁面中的事件僅為方向示例，不代表實時成分、實時點位或可執行報價。

## 非概率聲明

指數點位不是單一事件的發生概率，也不應被解釋為對現實結果的確定性預測。

## 非完整現實描述

任何世界狀態指數都依賴有限事件集合和明確方法邊界。它無法捕捉現實中的全部資訊，也可能受到資料、市場結構和映射判斷限制。

## 非專業建議

指數、文檔和相關資料不構成投資、交易、法律、稅務、會計或政策建議，也不保證任何結果或收益。

## 指數份額的性質

當前指數份額是記錄在 Signa 使用者帳戶中的交易持倉，不是發送到使用者錢包的 BEP-20 代幣，不能在使用者之間自由轉讓，也不能作為指數份額直接提現。使用者需要先賣出份額換回 USDT，再提現可用 USDT。

指數點位本身不是概率，也不是天然以 USDT 計價的資產價格。實際份額、買賣金額和費用以有效產品報價及訂單回執為準。

## 托管與可用性

使用者充值確認後，USDT 由 Signa 托管，帳戶餘額和持倉由平台帳本記錄。這不是全程自托管模式。多重校驗、分離控制和帳本記錄用於降低特定風險，但不構成存款保險或絕對安全保證。

指數持續計算不代表產品始終可以交易。資料異常、報價過期、流動性不足、區塊鏈故障、平台保護機制或其他風險事件都可能造成充值、交易或提現暫停、延遲。

## 費用和規則變更

當前公開規則包括 1% 買入開倉費和 0% 賣出平倉費。提現手續費、最低金額、訂單限額和區塊確認要求以操作頁面顯示為準，並可能隨產品規則更新。已經完成的歷史訂單保留成交時的實際記錄。

## 地區與參與資格

產品是否可以在某一國家或地區使用，取決於適用法律、產品規則和使用者自身情況。使用者有責任確認自己是否具備參與資格，並承擔與個人稅務和合規相關的責任。

事件價格可能不準確、缺乏流動性或出現中斷。AI 映射和規則校驗也可能產生錯誤、偏差或遺漏，不能消除全部風險。
