# 到期與滾動接續

<strong>滾動接續（Rolling Continuity）</strong>解決事件合約有限期限與世界狀態長期持續之間的期限錯配。

![當前週期事件退出、下一週期事件進入審查時點，而連續指數點位保持接續](/images/en/07-rolling-continuity-en.png)

## 基本流程

在預定審查時點：

1. 舊成分按當前規則完成最後一個有效週期的價格計算；
2. 已結算、即將到期或失去代表性的成分退出；
3. 新的合格事件按照同一目標狀態定義進入；
4. 新權重完成歸一化；
5. 新組合從現有指數點位繼續計算。

## 價格基準

新成分進入時，需要記錄明確的初始價格基準。指數只計算其進入後的價格變化，不把進入前已經發生的市場變化追溯計入指數。

## 避免機械跳變

滾動時不直接比較舊組合和新組合的絕對事件價格。兩組事件可能具有完全不同的命題和概率水平，直接拼接會產生沒有經濟含義的跳變。

連續性通過指數點位接續實現，而不是通過要求新舊合約價格相等實現。

## 提前結算和作廢

對於提前結算、作廢或價格停止更新的成分，應按照指數的異常事件規則處理。正式方法文件需要說明最後有效價格、臨時權重再分配和替代成分規則。

> 事件可以結算，狀態持續存在；成分不斷變化，指數保持連續。
