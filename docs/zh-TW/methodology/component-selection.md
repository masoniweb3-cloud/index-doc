# 成分選擇

指數成分來自可觀察的真實事件合約。候選合約必須與目標狀態存在可說明的實質性因果聯繫，並滿足最低價格品質要求。

## 納入條件

一個事件通常需要同時滿足以下條件：

- 命題、結果條件和結算時間明確；
- 市場價格可穩定獲取；
- 事件結果對目標狀態存在清晰影響路徑；
- 影響方向能夠被一致映射；
- 與現有成分相比提供有效的新資訊；
- 剩餘期限適合當前指數審查週期。

## 因果路徑

每個候選事件都應形成一條簡明的暴露說明：

> 事件結果 → 現實機制 → 目標狀態變化

如果中間機制無法說明，或只能依賴寬泛聯想，事件不應進入指數。

## 資訊重疊

多個合約可能用不同表述重複同一事實。如果全部按獨立資訊納入，會放大單一命題的影響。

成分審查需要識別：

- 相同事件的不同截止日期；
- 同一結果的不同市場表述；
- 高度依賴同一前置事件的合約；
- 價格走勢長期近似且缺乏新增資訊的合約。

對於高度重疊的成分，可以擇優保留、合併暴露或降低權重。

## 排除情形

命題含糊、結算規則不穩定、價格長期失真、流動性不足或因果方向無法確定的事件，不進入指數。事件即使主題相關，也不構成自動納入理由。
