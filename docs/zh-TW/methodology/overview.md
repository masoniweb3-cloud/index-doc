# 構建流程

Signa Index 的構建目標，是把動態變化的事件合約集合轉換為定義一致、計算可復現、時間連續的世界狀態指數。

## 構造流程

完整流程由六個環節組成：

1. **定義目標狀態**：確定指數試圖衡量的持續性現實方向；
2. **選擇事件合約**：識別與目標狀態具有實質因果聯繫的合約；
3. **統一事件方向**：將不同合約結果映射為狀態增強或減弱；
4. **確定狀態暴露**：評估因果強度、資訊獨立性與價格品質；
5. **聚合狀態重定價**：計算方向調整後的加權價格變化；
6. **審查與滾動接續**：更新成分，同時保持指數點位連續。

## 構建原則

### 因果優先

事件能否進入指數，取決於其結果是否能夠通過清晰路徑改變目標狀態，而不是關鍵詞是否相似。

### 方向一致

所有成分必須映射到同一個狀態坐標，使不同事件的價格變化具有一致金融含義。

### 暴露而非熱度

權重反映事件對目標狀態的有效暴露，不直接等同於交易量、媒體關注或主觀重要性。

### 連續但不僵化

目標狀態和計算規則保持一致，成分則隨事件生命週期和資訊環境動態更新。

### 可解釋與可復現

每次成分納入、方向判斷、權重分配和規則變更，都應具有可記錄的依據。
