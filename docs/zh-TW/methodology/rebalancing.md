# 審查與再平衡

指數通過定期審查更新成分和權重，使事件集合繼續代表目標狀態，同時避免臨時判斷對指數造成不透明影響。

## 定期審查

每個指數應預先公佈審查頻率和生效規則。定期審查通常包括：

- 檢查現有成分是否仍然有效；
- 移除已結算、即將失去價格意義或不再相關的事件；
- 評估新出現的候選事件；
- 更新資訊重疊關係；
- 重新評估價格品質和狀態暴露；
- 歸一化下一週期權重。

## 再平衡生效

舊成分按照當前週期規則完成計算，新成分和新權重從預定生效時點開始使用。

再平衡本身不應產生指數收益。新組合繼承生效前的指數點位，並從新的價格基準開始貢獻變化。

## 臨時審查

當發生以下情況時，可以觸發規則明確的臨時審查：

- 事件合約提前結算或被作廢；
- 資料源長時間中斷；
- 合約結算條件發生重大爭議；
- 市場價格明顯失去可用性；
- 現實事件使原有因果路徑失效。

臨時審查用於維護方法有效性，不用於根據價格表現主動擇時。

## 審查記錄

每次審查應保存成分變更、方向、權重、排除理由、生效時間和執行版本，以支持復核與歷史解釋。
