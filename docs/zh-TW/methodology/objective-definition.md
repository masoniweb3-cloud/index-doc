# 目標狀態定義

構造世界狀態指數的第一步，不是尋找事件，而是定義指數要衡量的**目標狀態**。

目標狀態決定成分邊界、方向判斷、權重含義和指數解釋。定義含糊會把後續每一步的不確定性放大。

## 定義要求

一份可執行的目標狀態定義應包括：

### 狀態命題

用一句話說明指數試圖衡量的持續性現實方向，避免使用無法判斷增強或減弱的寬泛主題。

### 正向定義

明確哪些現實變化構成目標狀態增強。正向定義應描述現實機制，而不只是列舉幾個示例事件。

### 反向定義

明確哪些現實變化構成目標狀態減弱，並說明與正向狀態的邏輯關係。

### 時間範圍

說明指數關注的主導影響週期。短期衝擊和長期結構變化可能具有不同方向，必須先確定判斷坐標。

### 納入邊界

定義哪些事件類型可能構成有效暴露，以及哪些相鄰主題即使相關也應排除。

## 一個簡化示例

對於“和平進程”目標狀態：

- 狀態增強：衝突體系從升級轉向降級，談判、停火和穩定安排的實現程度提高；
- 狀態減弱：軍事升級、談判破裂或穩定安排失效的可能性提高；
- 排除邊界：只與地區經濟或國內政治相關、卻不存在明確衝突影響路徑的事件。

## 定義凍結

目標狀態應在指數發佈前完成審查並形成版本。指數運行過程中不能為了適應已有價格表現而隨意改變定義。
