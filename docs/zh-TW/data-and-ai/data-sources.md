# 資料來源

Signa Index 的基礎價格輸入來自可觀察的真實事件合約市場。資料來源必須能夠支持穩定採集、歷史重現和明確的時間記錄。

## 需要採集的資料

對於每份候選事件合約，至少需要記錄：

- 市場與合約標識；
- 原始命題文本和結果選項；
- 結算條件、截止時間和狀態；
- 價格及對應時間戳；
- 可用的成交、流動性或價差資訊；
- 資料源和抓取版本；
- 後續更正、作廢或結算記錄。

## 價格選擇

正式指數方法需要規定使用的價格類型，例如可執行中間價、最後成交價、時間加權價格或其他經過驗證的參考價格。

價格選擇應降低偶發成交、短時價差擴大或單點異常對指數的影響，同時保持規則可復現。

## 時間一致性

不同市場的更新時間、時區和暫停狀態可能不同。指數計算必須使用統一時間標準，並明確價格截點、缺失資料和延遲資料的處理方式。

## 多來源事件

同一事件可能在多個市場交易。是否合併多來源價格、選擇主要市場或建立來源優先級，應由指數規則事先確定。

資料來源變化需要記錄，不能在沒有披露的情況下用新來源改寫歷史輸入。
