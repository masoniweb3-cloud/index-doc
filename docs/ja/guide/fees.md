# 手数料

| 操作 | 現行手数料 | 収集者 |
| --- | ---: | --- |
| 入金 | Signa 入金手数料なし | BSC ウォレット転送のBNBガスを課金 |
| 購入 | 元本の1% | Signa 購入手数料 |
| 売却 | 0% | 現行の終了手数料なし |
| 出金 | 出金ページに表示された通り | 要求された合計から差し引かれる |

## 1%とは具体的に何ですか？

現在の<strong>1%は購入時に課される購入手数料です</strong>。これはユーザーが購入して指数持分を作成する際に徴収され、指数持分計算に用いる元本とは別に表示されます。

以下ではありません：

- 利益に基づく「利益税」;
- BSC 入金のガス;
- 出金手数料;
- 指数レベルへの直接調整。

### 購入例

元本<strong>100 USDT</strong>と1%の購入手数料の場合：

| 項目 | 金額 |
| --- | ---: |
| 指数持分計算に使用される元本 | 100 USDT |
| 1% 購入手数料 | 1 USDT |
| 支払合計 | 101 USDT |

利用可能残高は、元本だけでなく支払合計をカバーする必要があります。

## 売却手数料はありますか？

現行のルールでは：

- 購入手数料は購入時にのみ課されます;
- 売却終了手数料は<strong>0%</strong>です;
- 表示されている総売上金額は、現行ルールに基づき入金される予定の金額です。

完了した注文は、実行時に請求された実際の手数料を保持し、後でルールが変更されても書き換えられません。

## その他の費用

### BSC ガス

ウォレットから専用入金アドレスへのUSDTの送金には、BSCネットワークに支払われるBNBガスが必要です。ネットワークの状況により変動します。

### 出金手数料

固定の出金手数料が適用される場合があります。署名前に、ページには口座からの総控除額、手数料、および推定ウォレット受取額が表示されます。金額は手数料を上回る必要があります。

::: warning 確認ページが権威あるページです。
手数料やルールは変更されることがあります。購入、販売、または出金を行う前に、確認ページで現在のレート、実際の金額、見積もりの有効性を確認してください。
:::
