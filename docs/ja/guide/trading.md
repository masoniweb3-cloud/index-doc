# 取引方法

Signa では、ユーザーアカウントに記録される指数持分を取引します。購入時は USDT を使って特定のテーマと方向のポジションを作り、売却時は保有する指数持分を現在のクォートに基づいて USDT に戻します。

::: info 指数持分はオンチェーンのトークンではありません
指数持分はウォレットに送られず、現在は他のユーザーに転送できず、直接引き出すこともできません。まずUSDTに売却し、その後利用可能なUSDTを引き出してください。
:::

## テーマを選んで、次に方向を選択

| あなたの見解 | 選択 | 一般的な行動 |
| --- | --- | --- |
| 対象状態は強くなる | ロング指数 | 構成市場がテーマを支持するほど上昇 |
| 対象状態は弱くなる | ショート指数 | 構成市場がテーマに反対するほど上昇 |

和平プロセステーマの場合、停戦、交渉、関連イベントの集団的評価が和平に有利になると予想する場合はロングを選択します。その状態が弱くなると思う場合はショートを選択してください。

::: info ショートは「売る」ではありません
売ることは既に保有している指数持分を減らすだけです。ポジションなしで売却してショートを開設することはできません。逆のエクスポージャーを得るには、対応するショート指数を購入してください。
:::

## 購入

1. テーマを開き、ロングまたはショートを選びます。
2. 「購入」を選択し、USDTの元本を入力します。
3. 推定持分数、参照水準、購入手数料、および合計支払額を確認します。
4. サーバー見積もりをリクエストし、インデックス価格、手数料、インデックスのバージョン、および有効期限を固定します。
5. カウントダウンが終了する前に確認してください。そうでない場合は新しい見積もりをリクエストします。
6. 「保有」と「履歴」で持分数と取引記録を確認します。

## 売却

1. 取引パネルで「売却」を選択するか、保有から「クイック売却」を開きます。
2. ポジションを選択して持分数を入力するか、25%、50%、または全てを選択します。
3. 総収益、クローズ手数料、および推定USDT受取額を確認します。これは現時点の見積もりであり、将来の退出価格を保証するものではありません。
4. サーバー見積もりをリクエストし、有効期限前に確認します。
5. 執行された指数持分は削除され、USDTが利用可能残高に入金されます。

サインインしているアカウントが実際に保有している指数持分のみを売却できます。

## なぜ取引が利用できない可能性がありますか？

新しい見積もりや注文は次の場合に一時停止されることがあります：

- 最新の指数価格が存在しないか古くなっている場合；
- 取引、注文ルーティング、または取引後処理が準備できていない場合；
- 安全条件により新しい注文が無効にされる必要がある場合；
- 注文が最小/最大範囲外である場合、または買いが利用可能なUSDTを超える場合；
- 売却が現在の保有量を超える場合。

既存の保有および履歴は引き続き表示されます。利用できない指数価格はゼロとして扱われることはありません。

## 指数レベルに対する見積もり

指数レベルは状態の変化を記録します。これはUSDTで表示されるオンチェーンのトークンではありません。製品は参照レベルを使用して指数持分数と販売額を計算し、期間限定のサーバー見積もりを発行します。

有効な確認ページの見積もりのみが実行可能です。過去のレベル、チャート、期限切れの見積もりは実行可能な価格ではありません。
