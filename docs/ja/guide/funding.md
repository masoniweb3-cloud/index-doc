# 入金と出金

Signaは現在、**BNB Smart Chain（BSC、Chain ID 56）**上の**USDT（BEP-20）**で入金と出金を処理しています。

::: info 資金の保管方法
各アカウントは入金を識別する専用の BSC アドレスを使用しています。資金は、システムがネットワーク、USDT コントラクト、受取人、金額、およびブロック確認を検証した後にのみ入金されます。入金された USDT は Signa により管理され、入金と出金の制御の分離、複数のチェック、および照合可能な台帳を通じて管理されます。出金はアカウントに紐付けられた BSC ウォレットにのみ送信され、新しいウォレット署名が必要です。
:::

::: danger これを省略しないでください
入金ページに指定されている BSC USDT のみを送信してください。別のトークンを送ったり、Ethereum、Polygon、Tron、その他のネットワークを利用した場合、資金が永久に失われる可能性があります。
:::

## 入金方法

1. サインインして、[入金] を開きます。
2. ページに表示されている **BNBスマートチェーン (BEP-20)**と USDT コントラクトを確認します。
3. 金額を入力して接続されたウォレットを呼び出すか、専用の BSC 入金アドレスをコピー/スキャンして他のウォレットから送金します。
4. 表示されている最小入金額を満たしていることを確認してください。
5. 送金後、ステータスが「Submitted」から「Detected」、そして「Credited」に変わるのを待ちます。

ウォレットには BNB のガス代も表示されます。これは BSC ネットワークへ支払う手数料であり、Signa の1%の購入手数料とは別です。

### 金額が最小未満の場合はどうなりますか？

システムはチェーン上の転送を記録する場合がありますが、取引残高に入金されることはなく、自動回復を保証するものではありません。現在の最小金額は入金ページに表示されています。

## 入金はいつ反映されますか？

ウォレットステータスが「送信済み」であっても、Signa が資金を入金したことを意味するわけではありません。システムは以下を行う必要があります：

1. 正しい USDT 転送を BSC 上で検出する;
2. 受取人、トークンコントラクト、および金額を確認する;
3. 表示されている確認数を待つ;
4. 利用可能な取引残高に入金する。

入金履歴には、取引ハッシュ、確認の進行状況、および最終ステータスが表示されます。

## 出金方法

1. [出金] を開き、出金可能残高を確認します。
2. 金額を入力してください。ページには、最小額、1回あたりの最大額、UTCの日次限度額、手数料、および推定ウォレット受取額が表示されます。
3. 送金先を確認してください。現在、出金はサインインしているアカウントに関連付けられたBSCウォレットにのみ返されます。
4. ウォレットで認証に署名してください。これは金額、手数料、送金先、ワンタイムのノンスを確認します。秘密鍵は表示されません。
5. 「最近の出金」で「処理中」「BSCへ送信済み」「完了」の各ステータスを確認します。

## 進行中の出金

要求された金額はまず利用可能残高から予約されます。転送が送信されなかったこと、またはオンチェーンのトランザクションが確実に失敗したことをシステムが確認した後にのみ返されます。

ネットワークタイムアウトが発生した場合、ブロードキャストの状態が不明確な場合、またはトランザクションハッシュが既に存在する場合、出金は最終結果が判明するまで進行中のままです。再度送信しないでください。予約済み資金を早く返すと同じ資金が二重に支払われる可能性があります。

## ステータスの理解

### 入金

- **提出済み:**ウォレットがトランザクションを送信しました；Signa がオンチェーンで待機しています。
- **検出済み:**正しい転送が確認されました；必要な確認が保留中です。
- **入金済み:**資金が利用可能なSigna残高にあり、取引可能です。

### 出金

- **処理中:**チェックやオンチェーン準備が行われる間、金額は予約されます。
- **BSCに提出済み:**トランザクションがブロードキャストされ、最終確認を待っています。
- **完了:**オンチェーントランスファーが確認されました。

ステータスが長期間変わらない場合は、[入出金のトラブルシューティング](/ja/guide/troubleshooting)を参照し、ウォレットアドレスとトランザクションハッシュを保持してください。

::: tip 製品ページが値の権威情報です
最小額、限度額、出金手数料、必要な確認回数は変更される場合があります。資金操作を送信する前に最新値を確認してください。
:::
