# Signa Indexの始め方

Signa Indexは、同じ現実テーマを扱う複数の予測市場を1つの連続指数にまとめます。現在の製品では、ユーザーはUSDTでロングまたはショートの指数持分を購入し、後から保有持分を売却できます。

## まず知っておくべき6つのこと

1. **現在、製品はBNB Smart Chain(BSC)を使用しています。**入出金はBSC USDT(BEP-20)を使用します。
2. **各テーマには2つの方向があります。** ロング指数はテーマの強まりに連動し、ショート指数は反対方向に動きます。
3. **購入はポジションを開き、売却は保有量を減らします。** 売却で反対方向のポジションが開くわけではありません。反対の見方を表すにはショート指数を購入します。
4. **現在の1%手数料は購入時にかかる購入手数料です。** 利益税や売却手数料ではなく、現在の売却手数料は0%です。
5. **指数持分はウォレット内のトークンではありません。** Signaアカウントに記録され、他のユーザーへ移転できません。出金前に売却してUSDT残高へ戻す必要があります。
6. **入金後の資金はSignaが保管します。** 専用アドレスで入金を識別し、複数の検証と照合可能な台帳でUSDTを管理します。全期間を通じたセルフカストディ方式ではありません。

## 完全なユーザーフロー

### 1. サインインと資金準備

BSC対応ウォレットを接続してサインインしてください。接続されたウォレットからの入金には、ネットワークガスとして少量のBNBが必要です。

### 2. 入金BSC USDT

未払い入金。接続されたウォレットから直接送金するか、割り当てられた専用BSC入金アドレスをコピーしてください。必要な確認が完了すると、USDTは利用可能な取引残高に加算されます。

### 3. テーマと方向性を選ぶ

[6つのローンチ指数](/ja/indexes/)からテーマを選び、その状態が強まるか弱まるかを判断して、ロング指数またはショート指数を選びます。両者は独立した連続水準であり、合計が100になるYES/NO価格ではありません。

### 4. 見積もりを取り、購入を確定する

購入元本となる USDT 金額を入力します。システムには参照指数水準、推定持分数、購入手数料、合計支払額が表示されます。サーバークォートはカウントダウン期間中のみ有効です。

### 5. ポジションの閲覧または売却

実行後、ホールディングスは指数持分、平均エントリー価格、現価、未実現損益額を表示します。売却は口座に既に保有している指数持分を減らすことしかできません。

### 6. 出金

販売後に利用可能なUSDTは現在接続されたウォレットに引き出すことができます。新しいウォレット署名で金額、手数料、宛先住所が確認されます。

::: tip ライブプロダクトをチェックしてください
現在のレベル、ライブコンポーネント、手数料、限度額、取引の利用可能性は、[Signaウェブサイト](https://signaindex.com/)および注文確認ページで示されています。
:::
