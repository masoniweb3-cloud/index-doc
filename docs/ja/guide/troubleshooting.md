# 入出金トラブルシューティング

入金や出金に予想以上の時間がかかる場合、資金を再送信したり、再度リクエストを提出しないでください。確認、混雑、状態の同期には時間がかかることがあり、重複は調整を難しくします。

## 入金が反映されない場合

以下を順に確認してください：

1. ネットワークが<strong>BNBスマートチェーン（BSC、Chain ID 56）</strong>であること；
2. 資産が入金ページに指定された<strong>USDT（BEP-20）</strong>であること；
3. 受取人が現在のアカウント専用アドレスと完全に一致していること；
4. 金額が表示された最低額を満たしていること；
5. ブロックエクスプローラーで成功と表示されていること；
6. ページがまだ確認待ちでないこと。

最低額未満の送金、誤ったネットワーク、誤ったトークンの使用、または誤ったアドレスへの送金は、回復が保証されません。

## 出金が処理中のまま

処理中とは、金額は確保されているが、最終的なオンチェーン結果は不明であることを意味します。

- 同じ出金を再度提出しないでください。
- ウォレット通知だけに頼らないでください。
- ハッシュが表示されている場合は、BSCブロックエクスプローラーで確認してください。
- タイムアウトや不明瞭なブロードキャストは、残高を直ちに解放せず、二重支払いを防ぎます。

予約された資金は、システムが何も送金されなかったことを確認するか、チェーンが確実に失敗を報告して初めて返金されます。

## サポートに準備するもの

Signaウェブサイトに記載された公式チャネルでレビューを依頼する際、以下を提供してください：

- サインインしているウォレットアドレス；
- BSCトランザクションハッシュ；
- 金額；
- おおよその時間とタイムゾーン；
- 現在のページのステータス;
- 必要に応じて、機密情報を含まないスクリーンショット。

::: danger これらを絶対に提供しないでください
Signaは、プライベートキー、シードフレーズ、ウォレットのパスワード、またはデバイスの遠隔操作を求めることは決してありません。要求する人を信頼しないでください。
:::
