# 政治権力指数

政治的権力指数は、政治的主体が制度的権力を獲得、保持、移転、または喪失する能力の変化を測定します。

政治的権力は、有名度、世論調査の注目度、または単一選挙の勝利確率と同じではありません。対象状態は、どの権力を測定するか、どの制度的範囲内で、どのメカニズムを通じて測定するかを定義する必要があります。

## 可能な次元

- 執行権力の獲得または保持;
- 立法権の取得;
- 安定した統治連立の形成;
- 主要な任命や政策課題の推進;
- 党または制度内での指導的地位の保持。

## 候補例

選挙結果、議会議席、連立形成、任命、弾劾または解職手続き、および制度的支配を変える司法判断は、有効な露出を生み出す可能性があります。

## 重複評価を避ける

政治関連の市場には、同じ選挙を扱う候補者の勝敗、政党支配、州単位の結果など、互いに強く関連する命題が含まれることがあります。

指数は、共有される前提条件を特定し、同じ政治的結果を複数回、完全な重みでカウントすることを避けなければなりません。
