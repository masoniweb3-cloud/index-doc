# 技術進化指数

技術進化指数は、重要な技術が研究のブレークスルーから展開、普及、ガバナンス、社会的採用へと継続的に移行する様子を測定するものです。

これはテクノロジー企業の株価指数ではなく、企業価値を直接測定するものでもありません。構成要素は、技術力、利用可能性、普及、または制度環境を通じて対象状態に影響する必要があります。

## 可能な次元

- 中核能力のブレークスルー;
- 商業展開とスケーリング;
- コスト低下とインフラ成熟度;
- ユーザー、企業、または公共部門による採用;
- 規制の許可、制約、およびガバナンス;
- 安全性事故および公共の信頼。

## 候補例

ベンチマークとなるブレークスルー、主要なローンチ、承認、インフラマイルストーン、採用目標、またはシステム的な安全イベントが該当する場合があります。

## 時間的視点

短期市場反応と長期的普及効果は異なる場合があります。指数は主たる時間的視点を事前に定義し、短期の競争と長期の進化を方向決定で混同しないようにする必要があります。
