# ローンチ指数

Signa Index の初回リリースでは、現実世界に関する6つのテーマを扱います。各テーマには独立したロングとショートの方向があり、ロングは状態の強まり、ショートは状態の弱まりを表します。

以下のイベントは方向を理解するための例であり、現在採用されている構成要素ではありません。最新の指数水準、構成要素、取引状況は Signa の製品画面で確認できます。

| 指数 | ロング指数が通常上昇する状況 | ショート指数が通常上昇する状況 |
| --- | --- | --- |
| **中東平和指数**| 停戦の維持、交渉の進展、人質の解放、国交正常化、紛争の緩和 | 戦争の継続、軍事活動の激化、交渉の決裂、紛争の拡大 |
| **中国国家モメンタム指数**| 経済の強靭性、技術力、国際的影響力、政策の安定性、対外安全保障の改善 | これらの要素の明確な悪化、または外部圧力の上昇 |
| **米国国家モメンタム指数**| 経済の強靭性、技術的優位、制度運営、政策実行、国際的影響力の改善 | 景気後退リスク、制度的対立、技術的優位、国際的影響力の弱まり |
| **欧州国家モメンタム指数**| 経済・通貨の強靭性、エネルギー安全保障、産業競争力、統合、国際的影響力の改善 | 経済、エネルギー、産業、統合、対外安全保障環境の悪化 |
| **AI 発展指数**| モデル能力、計算資源、導入、投資、発展を支えるガバナンス環境の前進 | 進歩の停滞、計算資源の制約、投資の縮小、導入の失速、規制の大幅な強化 |
| **暗号資産発展指数**| 利用拡大、規制の明確化、機関投資家の参加、インフラの成熟、主流金融との統合 | 利用縮小、規制による抑制、機関の撤退、重大なセキュリティ・信頼危機 |

::: info 例を読む
関連するニュースが現れても、インデックスが機械的に動くわけではありません。イベントは能動的要素であり、方向マッピングを通過し、市場価格の変化や重みを通じて貢献しなければなりません。
:::

## YESやNO

ロングとショートは、1つの二項契約のYES・NO結果ではありません。それぞれに連続したレベルがあります。100に足す必要はありません。ショートを買うことはロングを売ることとは異なります。
