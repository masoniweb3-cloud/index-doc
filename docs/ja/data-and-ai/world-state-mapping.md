# 世界状態の発見とマッピング

世界状態には、最初から用意されたティッカーや完全なデータ表はありません。現実テーマを巡るシグナルは複数の予測市場に分散し、絶えず現れ、消え、変化します。連続指数へ変換するには、関連性の高い市場を発見し、各結果が対象状態へどう影響するかを理解する必要があります。

それが**Signa独自開発のAI世界状態エンジン**の役割です。単なるキーワード検索や同一カテゴリーの平均ではありません。実際の予測市場を継続的に読み取り、Signa独自の発見・マッピングアルゴリズムで、個別イベントを説明可能、計算可能、継続更新可能な世界状態構造へ整理します。

::: info Signaのコア技術層
予測市場イベント価格を形成します。Signaの独自AIは有効な信号を発見し、因果関係、方向性、強さ、情報の重複を特定します。インデックス手法は、これらの構造化された結果を連続的なレベルに変換します。
:::

## 市場全体でシグナルを発見する

各レビューで、Signa AI は候補市場を改めて探索し、複数段階の検証を適用します。

1. **市場発見：** 対象状態へ影響し得る新しい命題を特定します。
2. **意味の正規化：** 結果条件、期間、決済基準、YES/NOの実際の意味を解析します。
3. **因果経路の抽出：** 「イベント結果 → 現実の仕組み → 対象状態」の経路を作り、キーワードだけのノイズを除外します。
4. **方向判定：** YESが対象状態を強めるか弱めるかを判断します。
5. **エクスポージャー評価：** 影響規模、因果強度、結果の識別性、データ信頼性を構造化スコアへ統合します。
6. **重複・代表性チェック：** 重複命題、共通の前提条件、同一イベント群を検出し、二重計上を避けます。
7. **継続ローリング：** 旧市場の満期に合わせて代替市場を発見し、状態を継続的に表現します。

したがって、Signa Indexは予測市場価格を読むだけでなく、予測市場を現実のトレンドのためのインデックス言語に再構成しています。

## なぜこれは一般的なAI要約ではないのか

一般的な言語モデルはニュースを要約できますが、イベント契約が該当するかどうかを単独で判断することはできません。Signa AIは明示的なターゲット状態定義、因果層、方向ルール、品質制約、重複除去、バージョン連続性の下で動作します。

AI構造化された証拠を抽出します。独自のアルゴリズムは一貫したスコアリングと適格性チェックを適用します。同じ入力、ルール、バージョンが、レビュー可能な構造化された結果を生み出すべきです。明確な因果経路を欠いたりルールを満たさない市場は、単に関連しているように見えるからといって含まれません。

## AIは価格発見を行いません

「発見」とは、対象状態に関連する効果的な市場や構造的なシグナルを見つけることを意味します。イベント価格は依然として実際の予測市場参加者から決定されます。Signa AIはテキストから確率を発明したり、インデックスレベルを直接生成したりしません。

責任は分かれています:

1. **予測市場**がイベント価格を形成します。
2. **Signa AI**が候補を発見し、因果関係、方向、エクスポージャーをマッピングします。
3. **指数手法**が構造と価格を連続系列へ変換します。

## 強い能力には強い制約が必要です

自由形式の AI テキストは、決してインデックス結論として扱われません。各発見とマッピングは構造化された記録となります：正規化命題、ターゲット状態定義、ロング/ショート判断、因果説明、重複分析、データおよびモデルのバージョン、ルール検証結果。

## ルールが優先されます

AI 出力は構造化された分析入力であり、価格決定ではありません。明示的なルールは適格性、方向の一致、表現、データの最新性、バージョンの継続性を制約します。候補セットがすべてのチェックに合格した後にのみ、新しい有効なインデックスバージョンが形成されます。もし合格しなければ、単に更新を続けるために誤解を招くレベルを公開することはありません。
