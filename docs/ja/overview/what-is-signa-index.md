# Signa Indexとは何ですか？

**Signa Indexは、同じ現実世界のテーマに関連する複数の予測市場を組み合わせ、一つの継続的に更新される指数にまとめます。**

地域の和平プロセスが改善しているのか悪化しているのかを理解したいとします。一つの停戦が署名されるかどうかに関する市場だけでは不十分です。交渉再開、軍事行動のエスカレーション、制裁解除、第三者による仲介の進展など、すべてが和平プロセスに影響を与える可能性があります。

各イベントは特定の質問に答えます。Signa Indexはそれらを共通の方向に揃え、和平プロセスの変化を継続的に反映する指数を作ります。

株価指数が複数企業の株価を基に市場全体の動きを示すように、Signa Index はイベント契約の価格を基に、現実世界における長期的な状態変化を示します。

## 世界状態とは何ですか？

世界状態は、一つのイベントだけでは完全に説明できない持続的な現実世界の方向性であり、一連のイベントによって進展します。例えば:

- ある国の発展の勢いが強まっているか、弱まっているか。
- ある地域の地政学的な緊張が緩和しているか、悪化しているか。
- ある技術の普及が加速しているか、勢いを失っているか。
- 政治勢力が拡大しているか、縮小しているか。

個々のイベントは発生し、終了し、精算されますが、これらの状態は変化し続けます。

## Signaはイベントをどのように指数に変換するのですか？

Signaは以下の四つを行います:

1. 対象状態に実質的な影響を与えるイベントを特定する。
2. 各結果がその状態を強めるか弱めるかを判断する。
3. イベントの重要性と市場の質に基づいて重みを割り当てる。
4. 古いイベントの満期に合わせて新しいイベントを採用し、指数の連続性を保つ。

したがって、Signa Indexは単なるイベント確率の平均ではありません。それは市場による持続的な現実世界の方向性の継続的な再評価です。

## その指数とあなたが購入する指数持分の違いは何ですか？

三つの異なる層があります:

1. <strong>イベント契約：</strong>結果に対する市場価格を形成する、予測市場の具体的な問い。
2. <strong>Signa Index：</strong>複数のイベント契約を集約し、現実世界のテーマについてロングまたはショートの水準を継続的に計算する指数。
3. <strong>指数持分：</strong>Signa が指数水準に基づいて提示し、ユーザーのアカウントに記録する取引ポジション。

ユーザーは基礎となる予測市場契約ではなく指数持分を取引します。指数持分はウォレットに送信されるBEP-20トークンではありません。現在、他のユーザーに転送したり、オンチェーンで直接引き出したりすることはできません。退出するには、ユーザーはまずUSDTに指数持分を売り戻し、その後利用可能なUSDTを接続されたウォレットに引き出します。

指数レベルは本質的にUSDTで表示された確率やトークン価格ではありません。購入された指数持分の数と販売時に受け取るUSDTは、確認されたプロダクトの見積もりが有効である間に決定されます。

## 公式定義

> 世界状態指数は、イベント契約の価格を価格設定の基礎として利用し、離散的なイベントを世界状態マッピング、方向整合、状態露出の重み付け、および連続的なロールを通じて長期的な現実世界の状態エクスポージャーに結合する、ルールベースの合成指数です。
