# なぜ世界状態指数が必要なのか？

予測市場は特定の質問に答えるのが得意です：法案は通るか？交渉は合意に達するか？製品は予定通りに発売されるか？

しかし、人々が関心を持つのはしばしば一つの出来事ではなく、その背後にある持続的な変化です。

| 一つの出来事が答えること | 人々が本当に理解したいこと |
| --- | --- |
| 休戦合意は締結されるか？ | 平和プロセスは改善しているか、それとも悪化しているか？ |
| 重要な法案は通るか？ | 国の発展の勢いは強まっているか？ |
| 製品は予定通りに発売されるか？ | 技術の採用は加速しているか？ |
| 候補者は選挙に勝つか？ | 政治勢力は拡大しているか？ |

単一の市場は出来事の価格を付けることはできますが、これらの広範な質問には単独では答えることができません。

## 単一の出来事は一つのピースに過ぎません

平和プロセスは一つの休戦で決まるわけではなく、技術の採用も一つの製品発売で決まるわけではありません。重要な現実世界のトレンドは複数の出来事によって同時に形成され、各出来事は全体像の一部しか明らかにしません。

一つの市場だけを見ていると、局所的な変化を全体のトレンドと誤解してしまうことがあります。

## 状態は一つの契約で消滅しません

イベント契約には期限があります。結果が判明すると市場は清算され終了します。

しかし、平和プロセス、国家発展、技術進化は、一つの契約が清算されたからといって止まるわけではありません。新しい交渉、政策、節目が引き続き現れます。

これにより成熟度の不一致が生じます：期限付きの事件市場が、期限のない現実世界のトレンドを観察するために使われているのです。

## 「上昇」は出来事ごとに逆の意味を持つことがあります

休戦の確率上昇は通常、平和プロセスを強化します；軍事的エスカレーションの確率上昇はそれを弱めます。どちらの契約価格も上昇するかもしれませんが、同じ状態に対する意味は逆です。

関連市場を単純に平均することはできません。まず方向性を揃え、それから各出来事が対象状態にとってどれほど重要かを評価する必要があります。

## Signa Indexが解決すること

Signa Indexはこれらの散在し、短命で、方向性の異なる信号を整理します：

- 対象状態に真に影響を与える出来事を特定する；
- 正と負の出来事を共通の方向にマッピングする；
- 直接的で高品質な情報により重みを与える；
- インデックスが継続する間に、期限切れのイベントを新しいものに置き換えます。

結果は孤立したイベントの確率ではなく、実際の世界状態における変化を連続して記録するインデックス系列です。

## これは何を可能にしますか？

研究者は、市場が長期的なトレンドをどのように再評価するかを観察できます。インデックス商品は、1つの公的ルールセットを参照することができます。ユーザーは同じ状態に対する強化的または弱化的な見解のいずれかを表現できます。

予測市場は個々のイベントの価格を設定します；Signa Indexはそれらのイベントを現実世界のトレンドに整理します。
