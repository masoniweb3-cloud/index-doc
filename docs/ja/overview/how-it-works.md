# Signa Indexはどのように機能するのか？

一言で言えば：観察すべき対象を定義し、真に関連する出来事を同じ方向に揃え、それらを連続的な指数にまとめる。

以下の例は「平和プロセス指数」である。

![6ステップの構築プロセス：対象状態を定義、出来事を選択、方向を揃える、影響を割り当てる、価格変動を集計、連続的にロールする](/images/en/03-index-construction-flow-en.png)

## 1. 観察対象を定義する

「平和」は広すぎる。指数は、対立システムがエスカレーションからデエスカレーションへ、再交渉へ、そしてより安定した合意に向かう動きを観察することを明確に指定する必要がある。

改善と悪化が何を意味するかも明示します。この定義は、その後のすべてのイベント判断に共通する基準であり、**対象状態**と呼びます。

## 2. 真に影響する出来事を見つける

Signaは次に予測市場全体を見渡し、停戦、交渉、軍事的エスカレーション、制裁の変化、第三者の仲介など、平和プロセスを変え得る出来事を探す。

すべての候補は次の問いに答える必要がある：

> この結果はどのようなメカニズムで対象状態を変えるのか？

類似キーワードや最近の人気だけでは不十分である。出来事には改善または悪化への説明可能な道筋が必要である。

## 3. 反対の出来事を同じ方向に置く

価格上昇は逆の意味を持つことがある：

- 停戦の可能性が高まることは通常、平和プロセスを強化する;
- 軍事エスカレーションの可能性が高まることは通常、平和プロセスを弱化させる。

Signaは両方を一つの座標にマッピングする。対象状態に有利な変化は正、逆に不利な変化は負である。これによって、表現の異なる市場も一緒に計算できる。

## 4. 各出来事の重要性を決定する

中央停戦合意を扱う市場は、象徴的な会議より通常、平和プロセスにより影響を与える。継続的で信頼性のある価格を持つ市場は、停止している市場よりも有用な情報を提供する。

Signaはすべての出来事に同等の影響力を与えるわけではない。評価するのは：

- 出来事の影響が直接的かつ重要か;
- 他の出来事を繰り返すのではなく、新しい情報を提供するか;
- 市場価格が連続的で観察可能であり、十分な品質かどうか。

これらの評価から、各イベントの**状態エクスポージャー・ウェイト**を決定します。

## 5. 総合指数の変化

この指数は、方向の調整と加重後のイベント価格の変化を集計します。

複数の重要な市場が和平プロセスの改善を共同で支持する場合、指数は上昇します。市場が紛争の激化をますます織り込む場合、指数は下落します。

この指数は市場の評価がどのように変化するかを測定するものであり、イベントの現在の確率を平均するものではありません。

## 6. 古いイベントを新しいイベントと置き換える

停戦交渉が終了し、新たな交渉や紛争が出現します。レビュー時点で、Signaは、解決済み、期限切れ、または代表性のないイベントを削除し、同じ基準のもとで新しいイベントを採用します。

新しいバスケットは既存の指数レベルから継続され、再スタートはしません。これが**ローリング継続性**です。

## 最終的な結果は何ですか？

結果はイベントが発生する確率の一つではありません。それは、市場が現実の世界状態をどのように再評価するかを継続的に反映する指数曲線です。

> イベントは決済されますが国家は存続します。構成要素は変わりますが、指数は連続性を保ちます。
