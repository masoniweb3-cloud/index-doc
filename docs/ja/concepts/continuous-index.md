# 連続指数

単一のイベント契約は決済後に終了しますが、世界状態は進化を続けます。**連続指数**は、一貫した対象状態と計算ルールを維持することで、変化するイベントセットをひとつの連続した価格シリーズに接続します。

## 連続性の源

連続性には恒久的な構成要素は必要ありません。それは次の三つの安定した要素から生じます：

1. 目標状態の定義が一貫していること；
2. 方向性、加重、および計算ルールが一貫していること；
3. 構成要素の変更が既存のインデックスレベルから継続されること。

## 構成要素の変更は状態のリターンではない

レビュー時点でのイベントの追加または削除は、状態を観測するために使用されるツールを更新します。それは対象状態自体の変更として扱うべきではありません。

新しい構成要素は、その新しい有効期間からのみ価格変動に寄与します。交換だけではインデックスのジャンプは生じません。

## 比較可能性

連続したシリーズはユーザーが以下を観察できるようにします：

- 時間経過に伴う状態方向の変化；
- 市場の再評価の速度と大きさ；
- 世界の状態インデックス間の相対的パフォーマンス；
- インデックスと現実世界のタイムラインとの関係。

## 連続が不変を意味するわけではない

方法論は更新可能ですが、過去の比較可能性に影響する変更には記録、発効日、およびバージョンの注記が必要です。主要な方法論の変更は、履歴を書き換えるのではなく、新しいインデックスバージョンを必要とする場合があります。
