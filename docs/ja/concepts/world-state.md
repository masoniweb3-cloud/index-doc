# 世界状態

**世界状態**とは、複数のイベントから読み取られ、単一イベントの存続期間を超えて時間とともに変化し続ける、現実世界の方向性です。

抽象的な話題やニュースタグの集合ではありません。有効な世界状態には次のものが必要です:

- **持続性：** 1つのイベント契約が決済されても終わらないこと。
- **方向性：** 強まっているか弱まっているかを判断できること。
- **経済的意味：** その変化が、説明可能なリスク、機会、意思決定価値を生むこと。

## 状態と出来事

出来事は境界のある命題であり、状態は持続する座標です。

![短期のイベント契約は個別に満期を迎えますが、長期の世界状態は続きます。](/images/en/02-event-vs-state-en.png)

「当事者はある日までに停戦に署名するか？」は出来事です。「紛争システムはエスカレーションからデエスカレーションに移行しているか？」は状態です。前者は決着しますが、後者は交渉、軍事行動、政治的取り決めによって形成され続けます。

## 状態要因

複数の出来事にわたる価格変動は共通の方向性を含むことがあります。Signa Indexはこの共通の方向性を**状態要因**として扱います。

これは伝統的な金融での証券群における共通リスク要因を特定することに類似しています。ただし、その情報は企業のキャッシュフローやマクロ価格ではなく、出来事の結果と現実に対する因果的意味から得られます。

## 目標状態の定義

すべての指数は、少なくとも以下を網羅する明確な目標状態の仕様が必要です:

1. 状態の名前と経済的意味;
2. 強化と弱体化の基準;
3. 許容される出来事影響の経路;
4. 明示的に除外された隣接テーマ;
5. 関連する時間軸とレビュー頻度。

この定義は、構成要素の選択、方向性マッピング、および指数計算の共通基盤です。
