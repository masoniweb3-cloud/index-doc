# イベント契約

**一般に「予測市場」と呼ばれるものを、Signa Indexの文書ではイベント契約として扱います。**

あるイベントについて予測市場が開かれたという場合、通常は参加者が一つの具体的な質問に対する複数の結果を取引し、答えが確定した後に事前ルールに基づいて市場が決済されることを意味します。

例えば:

> 今年の終わりまでに、ある国は利下げを行うでしょうか？

市場には YES および NO の結果があるかもしれません。取引によって市場価格が形成され、結果は事前に書かれたルールに従って年末に決定されます。

この文書では、**明確な問い、観測可能な価格、満期、決済手順を持つ具体的な市場単位**をイベント契約と呼びます。

## なぜこの用語を使うのですか？

「予測市場」は、製品やプラットフォーム全体、あるいは1つの特定の質問を意味することがあります。計算の精度のために、Signa は指数に含めることができる特定の市場を指すために「イベント契約」を使用します。

1つの イベント契約 は、1つの限定された質問を表します。1つの Signa Index は、永続的な実際の 世界状態 を記述するために複数の イベント契約 を使用することがあります。

## どのような情報を提供しますか？

その価格は、参加者が現在どのように結果を評価しているかを反映します。YES の価格が上昇する場合、通常、市場がその結果により大きな重みを置いていることを意味します。価格が下落する場合は、より少ない重みを意味します。

Signa Index は、確率を独自に生成するモデルを使用するのではなく、実際の市場によって形成された観察可能な変化を使用します。

イベント契約 は価格入力であり、指数が最終的に表す永続的な状態ではありません。

## 基本的な適格要件

候補契約は一般的に次の条件を満たしている必要があります:

- 明確で検証可能な命題;
- 定義された YES, NO、またはその他の結果;
- 公開された決済基準および期限;
- 継続的にアクセス可能な市場価格;
- 指数計算に十分な価格の質;
- 対象状態 への説明可能な因果関係。

## YES は肯定を意味するわけではありません

YES は単に質問の命題が真であることを意味します。それは必ずしも観察された状態が改善することを意味するわけではありません。

例えば、「紛争は激化するか？」のYES価格が上昇すると、和平プロセスの状態が弱まる可能性があります。したがって、イベント契約は計算される前に状態指向マッピングを通過する必要があります。

## 満期と決済

イベント契約には有限の寿命があります。一度決済されると新たな価格変動は生じませんが、それらが示した世界状態は続く可能性があります。

Signaは、スケジュールされたレビューとローリング継続性を通じてイベントセットを更新し、短命の契約を持続的な状態系列に変換します。
