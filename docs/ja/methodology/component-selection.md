# コンポーネント選択

構成要素には、価格を観測できる実在のイベント契約を使用します。候補となる契約は、対象状態との間に説明可能で実質的な因果関係があり、最低限の価格品質基準を満たす必要があります。

## 包含基準

- 明確な命題、成果、決済時間;
- 安定してアクセス可能な市場価格;
- 対象状態への明確な影響経路;
- 一貫してマッピング可能な方向;
- 現行コンポーネントに対して有用な新情報;
- レビューサイクルに適した残存満期。

## 因果経路

各候補は簡潔なエクスポージャー文をサポートすべきである:

> イベント結果 → 現実世界のメカニズム → 目標状態の変化

メカニズムが広範な関連以上に説明できない場合、そのイベントは含めるべきではない。

## 情報の重複

異なる契約は同じ事実を繰り返すことがある。すべてを独立として扱うと一つの命題を過大評価する。レビューでは次を特定する:

- 同じイベントに対する異なる満期;
- 同じ結果に対する異なる表現の市場;
- 同じ前提条件に依存する契約;
- ほとんど新情報のない持続的に類似した価格。

高度に重複するコンポーネントは選択的に保持、結合、またはウェイトを下げることができる。

## 除外

曖昧な命題、不安定な決済ルール、歪んだ価格、流動性不足、または因果方向の不確実性は除外の理由となる。テーマの関連性だけでは適格性にはならない。
