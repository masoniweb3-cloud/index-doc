# 構築プロセス

Signa Indexは、変化するイベント契約の集合を、一貫して定義され、再現可能で、時間的に連続した世界状態指数に変換します。

## 6つの段階

1. **対象状態を定義する:** 永続的な現実世界の方向を指定して測定します。
2. **イベント契約を選択する:** その状態に実質的な因果関係を持つ契約を特定します。
3. **イベント方向を整合させる:** 結果を状態の強化または弱化に対応させます。
4. **状態エクスポージャーを決定する:** 因果の強さ、情報の独立性、および価格の質を評価します。
5. **状態の再評価を集約する:** 重み付き、方向調整済みの価格変動を計算します。
6. **レビューとロール:** 構成要素を更新しながら指数の連続性を保持します。

## 原則

### 因果関係第一

適格性は、結果が明確なメカニズムを通じて対象状態を変化させるかどうかに依存し、キーワードの類似性には依存しません。

### 方向の一貫性

すべての構成要素は同じ状態座標にマッピングされるため、価格変動が一貫した金融的意味を持ちます。

### 人気ではなくエクスポージャー

重みは、取引量、メディアの注目、または主観的重要性だけでなく、対象状態への実効的エクスポージャーを測定します。

### 硬直ではなく連続

対象状態とルールは、構成要素がイベントの寿命や情報条件に応じて更新されても一貫性を保ちます。

### 説明可能かつ再現可能

すべての採用、方向、重み、およびルール変更には、記録可能な根拠があるべきです。
