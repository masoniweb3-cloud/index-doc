# 満期とローリングの連続性

**ローリング継続性**は、有限なイベント契約と永続的な世界状態の間の満期不一致を解消します。

![現在期間のイベントはレビュー時点で終了し、次期間のイベントが入りますが、インデックスレベルは継続します。](/images/en/07-rolling-continuity-en.png)

## プロセス

予定されたレビュー時点では：

1. 古いコンポーネントは最終有効期間計算を完了します；
2. 決済済み、期限切れ、または代表性のないコンポーネントは除外されます；
3. 新しい適格イベントは同じ目標状態定義の下で追加されます；
4. 新しいウェイトは正規化されます；
5. 新しいバスケットは既存のインデックスレベルから継続されます。

## 価格基準

各新規コンポーネントは定義された開始価格を受け取ります。参入後の価格変動のみがカウントされ、それ以前の市場変動は遡って加算されません。

## 機械的なジャンプの回避

ローリングでは古いバスケットと新しいバスケットの絶対価格を比較しません。それらの提案や確率レベルは完全に異なる場合があるため、直接つなぐと経済的に意味のないジャンプが生じます。

継続性はインデックスレベルを繰り越すことから生じ、古い契約と新しい契約が同じ価格であることを要求しません。

## 早期決済と無効化

早期決済、無効、または古いコンポーネントは例外イベントのルールに従います。公開された方法論は、最後の有効価格、一時的なウェイト再分配、および代替ルールを定義する必要があります。

> イベントは状態が持続する間に決済されます；コンポーネントは変化しますが、インデックスは継続します。
