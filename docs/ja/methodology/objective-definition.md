# 対象状態の定義

最初のステップはイベントを見つけることではなく、**ターゲット状態**を定義することです。

対象状態は、コンポーネントの境界、方向、重みの意味、および解釈を決定します。あいまいさは後のすべてのステップで累積します。

## 要件

### 状態命題

永続的な方向性を一文で述べます。強化または弱化と判断できない広範なテーマは避けてください。

### ロング 定義

例示的なイベントだけでなく、メカニズムを通じて状態を強化する現実世界の変化を定義します。

### ショート 定義

状態を弱化させる変化と、強化との論理的関係を定義します。

### 時間的視野

主要な時間的視野を指定します。ショートのショックや構造変化は異なる方向を示すことがあります。

### 含有境界

潜在的に有効なイベントタイプと、除外されたままの隣接テーマを定義します。

## 簡易例

平和プロセスの状態の場合:

- 強化: 紛争システムがエスカレーションから脱エスカレーション、交渉、停戦、安定的な取り決めに向かって進む。
- 弱化: 軍事的エスカレーション、交渉の失敗、安定的な取り決めの崩壊の可能性が高まる。
- 除外: 明確な紛争メカニズムを伴わない地域経済や国内政治のイベント。

## 定義の凍結

対象状態は起動前にレビューされ、バージョン管理されるべきです。観測された価格パフォーマンスに合わせるだけで運用中に変更してはなりません。
