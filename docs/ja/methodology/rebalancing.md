# レビューとリバランス

予定されたレビューは、イベントセットが不透明で恣意的な判断なしに対象状態を引き続き表すように、コンポーネントとウェイトを更新します。

## 予定レビュー

各指数は、レビューの頻度と有効なルールを開示する必要があります。レビューでは通常以下を行います。

- 現在のコンポーネントが引き続き有効か確認する;
- 決済済み、期限切れ、または無関係なイベントを削除する;
- 新しい候補を評価する;
- 情報の重複関係を更新する;
- 価格の品質と状態エクスポージャーを再評価する;
- 次の期間のためにウェイトを正規化する。

## 有効性

古いコンポーネントは当期のルールの下で終了します。新しいコンポーネントとウェイトは、予定された有効時点で開始します。

リバランス自体はリターンを生み出すべきではありません。新しいバスケットは、事前の有効インデックスレベルを引き継ぎ、新しい価格基準値から開始します。

## 臨時レビュー

契約が早期に決済されたり無効になった場合、データソースが長期間利用できない場合、決済が重大に紛争中の場合、価格が使用不可になった場合、または元の因果パスが失敗した場合に、ルールは臨時レビューを引き起こすことがあります。

臨時レビューは方法論の妥当性を維持するものであり、パフォーマンスに基づく裁量的な市場タイミングではありません。

## レビュー記録

各レビューは、コンポーネントの変更、方向性、ウェイト、除外、有効時間、および実施バージョンを保存する必要があります。
