# World state

A **world state** is a real-world direction revealed by multiple events, extending beyond any single event's life and continuing to change over time.

It is not an abstract topic or a collection of news tags. A valid world state must have:

- **Persistence:** it does not end when one event contract settles.
- **Direction:** it can be judged as strengthening or weakening.
- **Economic meaning:** its change creates explainable risk, opportunity, or decision value.

## State versus event

An event is a bounded proposition; a state is a persistent coordinate.

![Short-term event contracts expire separately while a long-term world state persists.](/images/en/02-event-vs-state-en.png)

“Will the parties sign a ceasefire by a date?” is an event. “Is the conflict system moving from escalation to de-escalation?” is a state. The former can settle; the latter continues to be shaped by negotiations, military action, and political arrangements.

## State factor

Price changes across multiple events may contain a common direction. Signa Index treats this common direction as a **state factor**.

It is analogous to identifying a common risk factor across a group of securities in traditional finance, except that its information comes from event outcomes and their causal meaning for reality rather than corporate cash flows or macro prices.

## Target-state definition

Every index needs a clear target-state specification covering at least:

1. the state's name and economic meaning;
2. criteria for strengthening and weakening;
3. acceptable event-impact pathways;
4. explicitly excluded adjacent themes;
5. the relevant time horizon and review frequency.

This definition is the common basis for component selection, direction mapping, and index calculation.
