# State direction

**State direction** describes whether an event outcome strengthens or weakens the target state.

Direction alignment gives differently worded event contracts a common financial meaning.

![The same rise in YES can strengthen or weaken the target state, so a direction variable is required.](/images/en/04-direction-mapping-en.png)

## Direction variable

For component $i$, define:

$$
d_i \in \{-1,+1\}
$$

- $d_i=+1$: a higher contract price strengthens the target state.
- $d_i=-1$: a higher contract price weakens the target state.

The variable applies to contract-price changes. It is not a moral or political judgment about the event.

## Decision process

Direction mapping should answer, in order:

1. Which outcome becomes more likely when the contract price rises?
2. Through what real-world mechanism does it affect the target state?
3. Does that effect strengthen or weaken the state?
4. Are there material conditions that could reverse the main direction?

## Conditionality and ambiguity

Some events can have different effects in different contexts. A policy may strengthen a state in the short term but weaken it over a longer horizon.

If the dominant horizon or direction cannot be clearly determined under the index rules, the event should not be forced into the index. It can be excluded until a clearer proposition appears.

## Direction stability

Once admitted, direction should remain stable for the current effective period. It must not be changed retroactively because the market price moved.

If the underlying definition changes fundamentally, the issue should be handled through formal review with the reason and effective time recorded.
