# How does Signa Index work?

In one sentence: define what should be observed, align genuinely relevant events to the same direction, and combine them into a continuous index.

The “peace process index” remains our example below.

![The six-step construction process: define the target state, select events, align direction, assign exposure, aggregate price changes, and roll continuously.](/images/en/03-index-construction-flow-en.png)

## 1. Define what to observe

“Peace” is too broad. The index must specify that it observes a conflict system moving from escalation toward de-escalation, renewed negotiation, and increasingly stable arrangements.

It must also state what counts as improvement and deterioration. This definition is the common standard for all later event decisions and is called the **target state**.

## 2. Find events that genuinely affect it

Signa then looks across prediction markets for events that could change the peace process, such as ceasefires, negotiations, military escalation, sanctions changes, and third-party mediation.

Every candidate must answer:

> Through what mechanism would this outcome change the target state?

Similar keywords or recent popularity are not enough. The event needs an explainable path to improvement or deterioration.

## 3. Put opposite events on one direction

Price increases can carry opposite meanings:

- a higher probability of a ceasefire usually strengthens the peace process;
- a higher probability of military escalation usually weakens it.

Signa maps both to one coordinate. Changes favorable to the target state are positive; changes unfavorable to it are negative. Only then can differently worded markets be calculated together.

## 4. Determine how important each event is

A market covering a central ceasefire agreement will usually affect the peace process more than a symbolic meeting. A market with continuous, credible prices also provides more useful information than a dormant one.

Signa therefore does not give every event equal influence. It evaluates:

- whether the event's impact is direct and material;
- whether it adds new information rather than repeating another event;
- whether its market price is continuous, observable, and of sufficient quality.

These evaluations form the event's **state-exposure weight**.

## 5. Aggregate index change

The index aggregates event-price changes after direction adjustment and weighting.

When several important markets jointly support an improving peace process, the index rises. When markets increasingly price conflict escalation, it falls.

The index measures how market assessments change; it does not average the events' current probabilities.

## 6. Replace old events with new ones

Ceasefire negotiations end, while new negotiations and conflicts appear. At review points, Signa removes settled, expiring, or unrepresentative events and admits new ones under the same standards.

The new basket continues from the existing index level instead of restarting. This is **rolling continuity**.

## What is the final result?

The result is not one probability that an event will occur. It is an index curve continuously reflecting how markets reassess a real-world state.

> Events settle while states persist; components change while the index remains continuous.
