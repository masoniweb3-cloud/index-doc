# 연속 지수

개별 이벤트 계약은 정산 후 종료되지만 세계 상태는 계속 변화합니다. **연속 지수**는 일관된 목표 상태와 계산 규칙을 유지하면서, 달라지는 이벤트 집합을 하나의 연속적인 가격 시계열로 연결합니다.

## 연속성의 출처

연속성은 영구적인 구성 요소를 요구하지 않습니다. 이는 세 가지 안정적인 요소에서 나옵니다:

1. 목표 상태 정의가 일관성을 유지합니다;
2. 방향, 가중치, 계산 규칙이 일관성을 유지합니다;
3. 구성 요소 변경은 기존 지수 수준에서 계속 진행됩니다.

## 구성 요소 변경은 상태 수익률이 아닙니다

검토 시점에 이벤트를 추가하거나 제거하는 것은 상태를 관찰하는 데 사용되는 도구를 업데이트하는 것일 뿐, 목표 상태 자체의 변경으로 간주되어서는 안 됩니다.

새로운 구성 요소는 새로운 효력 기간부터만 가격 변화에 기여합니다. 교체만으로는 지수 점프를 발생시키지 않습니다.

## 비교 가능성

연속 시리즈를 통해 사용자는 다음을 관찰할 수 있습니다:

- 시간에 따른 상태-방향의 변화;
- 시장 재평가 속도와 규모;
- 세계 상태 지수 간의 상대적 성과;
- 지수와 실제 세계 타임라인 간의 관계.

## 연속적이라는 것이 불변을 의미하지는 않습니다

방법론은 업데이트될 수 있지만, 과거 비교 가능성에 영향을 주는 모든 변경 사항에는 기록, 발효일, 버전 노트가 필요합니다. 주요 방법론 변경은 역사를 다시 쓰는 대신 새로운 지수 버전을 필요로 할 수 있습니다.
