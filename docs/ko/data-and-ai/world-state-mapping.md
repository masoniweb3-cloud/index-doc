# 세계 상태 발견 및 매핑

세계 상태에는 미리 정해진 티커나 완성된 데이터 표가 없습니다. 현실 주제를 둘러싼 신호는 여러 예측시장에 흩어져 있으며 계속 나타나고 사라지고 변합니다. 이를 연속 지수로 만들려면 관련성이 높은 시장을 발견하고 각 결과가 목표 상태에 어떤 영향을 주는지 이해해야 합니다.

이것이 **Signa가 자체 개발한 AI 세계 상태 엔진**의 역할입니다. 단순한 키워드 검색이나 같은 카테고리의 평균이 아닙니다. 실제 예측시장을 지속적으로 읽고 Signa의 독자적인 발견·매핑 알고리즘을 이용해 개별 이벤트를 설명 가능하고 계산 가능하며 지속적으로 갱신 가능한 세계 상태 구조로 정리합니다.

::: info Signa의 핵심 기술 계층
예측시장이 이벤트 가격을 형성합니다. Signa의 독자 AI는 유효한 신호를 발견하고 인과관계, 방향, 강도, 정보 중복을 식별합니다. 지수 방법론은 이 구조화된 결과를 연속적인 지수 수준으로 변환합니다.
:::

## 시장 전반에 걸친 신호 발견

각 검토에서 Signa AI는 후보 시장을 다시 탐색하고 여러 단계의 검사를 적용합니다:

1. **시장 발견:** 목표 상태에 영향을 줄 수 있는 새로운 명제를 식별합니다.
2. **의미 정규화:** 결과 조건, 기간, 정산 기준, YES/NO의 실제 의미를 분석합니다.
3. **인과 경로 추출:** ‘이벤트 결과 → 현실 메커니즘 → 목표 상태’의 경로를 구성하고 키워드만 겹치는 노이즈를 제거합니다.
4. **방향 판정:** YES 결과가 목표 상태를 강화하는지 약화하는지 판단합니다.
5. **익스포저 평가:** 영향 규모, 인과 강도, 결과 구별성, 데이터 신뢰성을 구조화된 점수로 결합합니다.
6. **중복·대표성 검사:** 중복 명제, 공통 전제 조건, 동일 이벤트군을 식별해 이중 계산을 방지합니다.
7. **연속 롤링:** 기존 시장의 만기에 맞춰 대체 시장을 발견해 상태를 지속적으로 표현합니다.

따라서 Signa Index는 단순히 예측시장 가격을 읽는 것 이상을 하며, 예측시장을 실제 추세를 위한 지수 언어로 재구성합니다.

## 왜 이것이 일반적인 AI 요약이 아닌가

일반적인 언어 모델은 뉴스를 요약할 수 있지만, 이벤트 계약이 지수 기준에 부합하는지를 스스로 확정할 수는 없습니다. Signa AI는 명시적인 목표 상태 정의, 인과 계층, 방향 규칙, 품질 제약, 중복 제거, 버전 연속성 규칙 아래에서 작동합니다.

AI는 구조화된 근거를 추출하고, 독자 알고리즘은 일관된 평가와 적격성 검사를 적용합니다. 동일한 입력, 규칙, 버전은 검토 가능한 동일한 구조의 결과를 만들어야 합니다. 명확한 인과 경로가 없거나 규칙을 위반한 시장은 단지 관련 있어 보인다는 이유만으로 포함되지 않습니다.

## AI가 가격을 결정하는 것은 아닙니다

“발견”은 목표 상태와 관련된 유효한 시장과 구조적 신호를 찾아내는 것을 뜻합니다. 이벤트 가격은 실제 예측시장 참가자들이 형성합니다. Signa AI가 텍스트에서 확률을 임의로 만들거나 지수 수준을 직접 생성하는 것은 아닙니다.

책임은 다음과 같이 분리되어 있습니다:

1. **예측시장**이 이벤트 가격을 형성합니다.
2. **Signa AI**가 후보를 발견하고 인과관계, 방향, 익스포저를 매핑합니다.
3. **지수 방법론**이 구조와 가격을 연속 시계열로 변환합니다.

## 강력한 능력은 강력한 제약을 요구합니다

자유 형식 AI 텍스트는 결코 지수 결론으로 취급되지 않습니다. 각 발견과 매핑은 구조화된 기록이 됩니다: 정규화된 명제, 목표 상태 정의, 매수/매도 판단, 인과 설명, 겹침 분석, 데이터 및 모델 버전, 규칙 검증 결과.

## 규칙이 우선합니다

AI 출력은 구조화된 분석 입력이지 가격 결정이 아닙니다. 명시적인 규칙은 적격성, 방향 일관성, 대표성, 데이터 최신성, 버전 연속성을 제한합니다. 후보 집합이 모든 검사를 통과해야만 새 지수 버전에 반영됩니다. 조건을 충족하지 못하면 단순히 업데이트를 이어가기 위해 오해를 부를 수 있는 수준을 게시하지 않습니다.
