# 출시 지수

Signa Index의 첫 출시 버전은 현실 세계의 여섯 가지 주제를 다룹니다. 각 주제에는 독립적인 롱과 숏 방향이 있습니다. 롱은 상태의 강화를, 숏은 상태의 약화를 나타냅니다.

아래 이벤트는 방향을 이해하기 위한 예시일 뿐이며 현재 편입된 구성 요소가 아닙니다. 최신 지수 수준, 구성 요소, 거래 상태는 Signa 제품 화면에서 확인할 수 있습니다.

| 지수 | 롱 지수가 일반적으로 상승하는 경우 | 숏 지수가 일반적으로 상승하는 경우 |
| --- | --- | --- |
| **중동 평화 지수**| 휴전 유지, 협상 진전, 인질 석방, 관계 정상화 또는 분쟁 완화 | 전쟁 지속, 군사 활동 격화, 협상 실패 또는 분쟁 확산 |
| **중국 국가 모멘텀 지수**| 경제 회복력, 기술 역량, 국제 영향력, 정책 안정성 또는 대외 안보 개선 | 해당 요소의 뚜렷한 악화 또는 외부 압력 상승 |
| **미국 국가 모멘텀 지수**| 경제 회복력, 기술 리더십, 제도 운영, 정책 실행 또는 국제 영향력 개선 | 경기 침체 위험, 제도 갈등, 기술 리더십 또는 영향력 약화 |
| **유럽 국가 모멘텀 지수**| 경제·통화 회복력, 에너지 안보, 산업 경쟁력, 통합 또는 국제 영향력 개선 | 경제, 에너지, 산업, 통합 또는 대외 안보 환경 악화 |
| **AI 발전 지수**| 모델 성능, 컴퓨팅 자원, 배포, 투자 또는 발전을 지원하는 거버넌스 환경 개선 | 발전 정체, 컴퓨팅 제약, 투자 축소, 배포 부진 또는 규제의 현저한 강화 |
| **암호자산 발전 지수**| 채택 확대, 규제 명확화, 기관 참여 증가, 인프라 성숙 또는 주류 금융과의 통합 | 채택 축소, 규제 억제, 기관 이탈 또는 중대한 보안·신뢰 위기 |

::: info 예시를 읽으며
관련 뉴스가 나타난다고 해서 지수이 기계적으로 움직이는 것은 아닙니다. 이벤트는 능동적인 구성 요소여야 하며, 방향 매핑을 통과해야 하며, 시장 가격 변화와 가중치를 통해 기여해야 합니다.
:::

## YES 아니고 NO

롱과 숏은 하나의 이진 계약에서 나오는 YES/NO 결과가 아닙니다. 각 방향에는 독립된 연속 지수 수준이 있으며, 두 수준의 합이 100일 필요도 없습니다. 숏 매수는 롱 매도와 다릅니다.

## 전망과 무역

현재 수준, 방향, 실제 부품, 견적, 재고 정보는 [Signa 웹사이트](https://signaindex.com/)에 표시됩니다.

지속적인 업데이트는 [만료 및 롤링 연속성](/ko/methodology/rolling) 또는 사용자 흐름을 위한 [거래 방법](/ko/guide/trading)을 참고하세요.
