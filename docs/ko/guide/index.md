# Signa Index 시작하기

Signa Index는 동일한 현실 주제를 다루는 여러 예측시장을 하나의 연속 지수로 결합합니다. 현재 상품에서 사용자는 USDT로 롱 또는 숏 지수 지분을 매수하고, 이후 보유 지분을 매도할 수 있습니다.

## 먼저 알아야 할 여섯 가지 사항

1. **현재 상품은 BNB Smart Chain(BSC)을 사용합니다.** 입출금 자산은 BSC의 USDT(BEP-20)입니다.
2. **각 테마에는 두 가지 방향이 있습니다.** 롱 지수는 테마의 강화를, 숏 지수는 반대 방향을 추적합니다.
3. **매수는 포지션을 열고, 매도는 보유량을 줄입니다.** 매도한다고 반대 포지션이 열리는 것은 아닙니다. 반대 관점을 표현하려면 숏 지수를 매수합니다.
4. **현재 1% 수수료는 매수 시 부과되는 매수 수수료입니다.** 이익에 대한 세금이나 매도 수수료가 아니며, 현재 매도 수수료는 0%입니다.
5. **지수 지분은 지갑 토큰이 아닙니다.** Signa 계정에 기록되며 다른 사용자에게 이전할 수 없습니다. 출금하려면 먼저 매도해 USDT 잔액으로 전환해야 합니다.
6. **입금 후 자금은 Signa가 보관합니다.** 전용 주소로 입금을 식별하고 여러 검증과 조정 가능한 원장을 통해 USDT를 관리합니다. 전 과정 셀프 커스터디 방식은 아닙니다.

## 완전한 사용자 흐름

### 1. 로그인하고 자금을 준비하세요

BSC 호환 지갑을 연결하고 로그인하세요. 연결된 지갑에서 입금하려면 네트워크 가스를 위한 소량의 BNB도 필요합니다.

### 2. 입금 BSC USDT

입금 오픈 중. 연결된 지갑에서 직접 보내거나 할당된 전용 BSC 입금 주소를 복사하세요. 필요한 확인 절차가 완료되면, USDT 사용 가능한 거래 잔액에 입금됩니다.

### 3. 주제와 방향 선택

[6개 출시 지수](/ko/indexes/) 중에서 주제를 선택하고, 그 상태가 강화될지 약화될지 판단한 뒤 롱 지수 또는 숏 지수를 선택합니다. 두 지수는 합계가 100이 되는 YES/NO 가격이 아니라 서로 독립된 연속 수준입니다.

### 4. 견적을 받고 구매 확정을 확인하세요

USDT 원금 금액을 입력하세요. 이 시스템은 기준 지수 수준, 예상 지수 지분, 개장 수수료, 총 지급액을 보여줍니다. 서버 인용은 카운트다운 기간 동안에만 유효합니다.

### 5. 포지션 보기 또는 매도

실행 후 보유 지수 지분, 평균 진입가, 현재 가치, 실현되지 않은 손익계산서를 보여줍니다. 매도는 계좌에 이미 보유한 지수 지분만 줄일 수 있습니다.

### 6. 철수

판매 후 사용 가능한 USDT은 현재 연결된 지갑으로 인출될 수 있습니다. 새로운 지갑 서명으로 금액, 수수료, 목적지 주소가 확인됩니다.

::: tip 라이브 제품 확인
현재 수준, 실시간 구성 요소, 수수료, 한도, 거래 가능 여부는 [Signa 웹사이트](https://signaindex.com/)와 주문 확인 페이지에서 확인할 수 있습니다.
:::
