# 입금 및 출금

Signa는 현재 **BNB 스마트 체인(BSC, Chain ID 56)**에서**USDT(BEP-20)**의 입금 및 출금을 처리합니다.

::: info 자금 보관 방식
각 계정은 입금을 식별하기 위해 전용 BSC 주소를 사용합니다. 자금은 시스템이 네트워크, USDT 계약, 수취인, 금액 및 블록 확인을 검증한 후에만 적립됩니다. 적립된 USDT는 Signa에 의해 관리되며, 입출금 통제, 다중 검증, 조정 가능한 원장을 통해 관리됩니다. 출금은 계정과 연결된 BSC 지갑으로만 발송되며, 새로운 지갑 서명이 필요합니다.
:::

::: danger 이 내용을 건너뛰지 마세요
입금 페이지에 지정된 BSC USDT만 보내세요. 다른 토큰을 보내거나, 이더리움, 폴리곤, 트론 또는 다른 네트워크를 사용할 경우 영구적인 손실이 발생할 수 있습니다.
:::

## 입금 방법

1. 로그인 후 입금을 엽니다.
2. 페이지에 표시된 **BNB 스마트 체인(BEP-20)**및 USDT 계약을 확인합니다.
3. 금액을 입력하고 연결된 지갑을 호출하거나 전용 BSC 입금 주소를 복사/스캔하여 다른 지갑에서 전송합니다.
4. 금액이 표시된 최소 입금액을 충족하는지 확인하세요.
5. 송금 후, 상태가 제출됨에서 감지됨을 거쳐 적립됨으로 변경될 때까지 기다립니다.

지갑에는 BNB 가스 수수료도 표시됩니다. 이는 BSC 네트워크에 지불되며 Signa의 1% 매수 수수료가 아닙니다.

### 금액이 최소 금액 미만이면 어떻게 되나요?

시스템이 온체인 전송을 기록할 수 있지만 거래 잔고에 적립하지 않으며 자동 복구를 보장하지 않습니다. 현재 최소 금액은 입금 페이지에 표시됩니다.

## 입금은 언제 적립되나요?

지갑 상태가 '송금됨'이라고 해서 Signa가 자금을 적립했다는 의미는 아닙니다. 시스템은 다음을 수행해야 합니다:

1. 올바른 USDT 전송을 BSC에서 감지;
2. 수취인, 토큰 계약 및 금액을 검증;
3. 표시된 확인 수만큼 대기;
4. 사용 가능한 거래 잔고에 적립.

입금 내역은 거래 해시, 확인 진행 상황 및 최종 상태를 보여줍니다.

## 출금 방법

1. 출금을 열고 출금 가능 잔액을 확인합니다.
2. 금액을 입력하세요. 페이지에는 최소 금액, 거래별 최대 금액, UTC 일일 한도, 수수료 및 예상 지갑 수령액이 표시됩니다.
3. 목적지를 확인하세요. 출금은 현재 로그인된 계정과 연결된 BSC 지갑으로만 반환됩니다.
4. 지갑에서 승인을 서명하세요. 금액, 수수료, 목적지 및 일회성 논스를 확인하며, 개인 키를 공개하지 않습니다.
5. 최근 출금 내역에서 처리 중, BSC에 제출됨, 완료됨을 추적하세요.

## 진행 중인 출금

요청한 금액은 먼저 사용 가능한 잔액에서 예약됩니다. 시스템이 전송이 이루어지지 않았거나 온체인 거래가 최종적으로 실패했음을 확인한 후에만 반환됩니다.

네트워크 시간 초과가 발생했거나 온체인 전송 상태가 불분명하거나 거래 해시가 이미 생성된 경우, 최종 결과가 확인될 때까지 출금은 처리 중으로 유지됩니다. 다시 제출하지 마세요. 예약 자금을 너무 일찍 반환하면 같은 자금이 중복 지급될 수 있습니다.

## 상태 이해하기

### 입금

- **제출됨:**지갑에서 거래를 전송했으며, Signa에서 온체인을 기다리고 있습니다.
- **감지됨:**올바른 전송이 확인되었으며, 필요한 확인이 대기 중입니다.
- **입금됨:**자금이 사용 가능한 Signa 잔액에 있으며, 거래할 수 있습니다.

### 출금

- **처리 중:**금액이 확인 또는 온체인 준비 중에 예약됩니다.
- **BSC에 제출됨:**거래가 방송되었으며 최종 확인을 기다리고 있습니다.
- **완료됨:**온체인 전송이 확인되었습니다.

상태가 장기간 변경되지 않는 경우 [입출금 문제 해결](/ko/guide/troubleshooting)을 참조하고 지갑 주소와 거래 해시를 보관하세요.

::: tip 제품 페이지의 값이 최종 기준입니다.
최소 금액, 한도, 출금 수수료 및 필요한 확인 수는 변경될 수 있습니다. 자금 조작을 제출하기 전에 실제 값을 확인하세요.
:::
