# 수수료

| 거래 | 현재 수수료 | 징수 주체 |
| --- | ---: | --- |
| 입금 | 입금 수수료 없음 | 지갑 전송 시 BNB 가스 요금 징수 |
| 매수 | 원금의 1% | 매수 개시 수수료 |
| 매도 | 0% | 현재 매도 종료 수수료 없음 |
| 출금 | 출금 페이지에 표시된 금액 | 요청한 총액에서 차감 |

## 1%는 정확히 무엇인가요?

현재 1%는 매수 시 별도로 부과되는 개시 수수료입니다. 지수 지분 계산에 사용되는 원금과 구분해 표시됩니다.

다음이 아닙니다:

- 수익을 기준으로 부과되는 “세금”이 아닙니다.
- 입금 시 발생하는 BSC 가스비가 아닙니다.
- 출금 수수료가 아닙니다.
- 지수 수준을 직접 조정하는 항목이 아닙니다.

### 구매 예시

원금 100 USDT와 1% 매수 수수료:

| 항목 | 금액 |
| --- | ---: |
| 지수 지분 계산에 사용되는 원금 | 100 USDT |
| 1% 매수 수수료 | 1 USDT |
| 총 결제액 | 101 USDT |

사용 가능한 잔액은 원금만이 아니라 총 결제액을 충당해야 합니다.

## 판매 수수료가 있나요?

현재 규칙에 따르면:

- 매수 수수료는 매수할 때만 부과됩니다.
- 현재 매도 종료 수수료는 0%입니다.
- 표시된 총 판매 금액은 현행 규칙에 따라 입금될 것으로 예상되는 금액입니다.

완료된 주문은 실행 시 부과된 실제 수수료를 유지하며, 이후 규칙이 변경되더라도 재작성되지 않습니다.

## 기타 비용

### BSC 가스

USDT를 지갑에서 전용 입금 주소로 보내려면 BSC 네트워크에 BNB 가스가 필요합니다. 네트워크 상황에 따라 달라집니다.

### 출금 수수료

고정 출금 수수료가 적용될 수 있습니다. 서명하기 전에 페이지에는 계좌에서 차감되는 총액, 수수료, 예상 지갑 수령액이 표시됩니다. 금액은 수수료를 초과해야 합니다.

::: warning 확인 페이지가 권위적입니다.
수수료와 규칙은 변경될 수 있습니다. 구매, 판매 또는 출금하기 전에 확인 페이지에서 현재 환율, 실제 금액, 견적 유효성을 검토하시기 바랍니다.
:::
