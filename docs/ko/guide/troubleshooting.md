# 입금 및 출금 문제 해결

입금이나 출금이 예상보다 오래 걸리는 경우, 자금을 다시 보내거나 요청을 다시 제출하지 마세요. 확인, 혼잡 및 상태 동기화에는 시간이 걸릴 수 있으며, 중복은 정산을 더 어렵게 만듭니다.

## 입금이 반영되지 않음

아래 사항을 확인하세요:

1. 네트워크가 **BNB 스마트 체인(BSC, Chain ID 56)**인지;
2. 자산이 입금 페이지에 지정된 **USDT(BEP-20)**인지;
3. 수신인이 현재 계정에 대한 전용 주소와 정확히 일치하는지;
4. 금액이 표시된 최소 금액을 충족하는지;
5. 블록 탐색기에서 성공이 표시되는지;
6. 페이지가 아직 확인을 기다리고 있지 않은지.

최소 금액 미만 전송, 잘못된 네트워크 사용, 잘못된 토큰 사용 또는 잘못된 주소로 전송한 경우 복구가 보장되지 않습니다.

## 출금이 처리 중임

처리 중이란 금액은 예약되었지만 최종 온체인 결과는 알려지지 않았음을 의미합니다.

- 같은 출금 요청을 다시 제출하지 마세요.
- 지갑 알림만 믿지 마세요.
- 해시가 표시되면 BSC 블록 탐색기에서 확인하세요.
- 타임아웃이나 불분명한 방송은 잔액을 즉시 해제하지 않으며, 중복 결제를 방지합니다.

예약된 자금은 시스템이 아무 것도 전송되지 않았음을 확인하거나 체인이 실패를 확실히 보고한 후에만 반환됩니다.

## 지원 요청을 위해 준비할 사항

Signa 웹사이트에 나열된 공식 채널을 통해 검토를 요청할 때 다음을 제공하세요:

- 로그인한 지갑 주소;
- BSC 거래 해시;
- 금액;
- 대략적인 시간과 시간대;
- 현재 페이지 상태;
- 필요한 경우, 민감한 정보가 없는 화면 캡처.

::: danger 절대 제공하지 마세요
Signa는 절대 개인 키, 시드 문구, 지갑 비밀번호 또는 기기 원격 제어를 요청하지 않습니다. 요청하는 사람을 신뢰하지 마세요.
:::
