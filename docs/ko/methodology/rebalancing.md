# 검토 및 리밸런싱

예정된 검토는 이벤트 세트가 불투명한 임의 판단 없이 목표 상태를 계속 나타내도록 구성 요소와 가중치를 업데이트합니다.

## 예정 검토

각 지수는 검토 빈도와 유효 규칙을 공개해야 합니다. 검토는 일반적으로 다음을 수행합니다:

- 현재 구성 요소가 여전히 유효한지 확인;
- 확정되었거나 만료되었거나 관련 없는 이벤트 제거;
- 새 후보 평가;
- 정보 중복 관계 업데이트;
- 가격 품질과 상태 익스포저 재평가;
- 다음 기간을 위해 가중치 정규화.

## 효과성

기존 구성 요소는 현재 기간 규칙에 따라 완료됩니다. 새 구성 요소와 가중치는 예정된 발효 시간에 시작됩니다.

리밸런싱 자체는 수익을 생성하지 않아야 합니다. 새 바스켓은 사전 발효 지수 수준을 상속하며 새로운 가격 기준선에서 시작합니다.

## 특별 검토

계약이 조기에 정산되거나 무효가 되거나, 데이터 소스가 장기간 실패하거나, 정산이 실질적으로 논쟁이 되거나, 가격이 사용 불가능해지거나, 원래의 인과 경로가 실패할 때 규칙이 특별 검토를 촉발할 수 있습니다.

특별 검토는 방법론적 유효성을 유지하며, 성과 기반 재량적 시장 타이밍이 아닙니다.

## 검토 기록

각 검토는 구성 요소 변경, 방향, 가중치, 제외, 발효 시간 및 구현 버전을 보존해야 합니다.
