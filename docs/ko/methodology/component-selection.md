# 구성 요소 선택

구성 요소에는 가격을 관찰할 수 있는 실제 이벤트 계약을 사용합니다. 후보 계약은 목표 상태와 설명 가능하고 실질적인 인과관계가 있어야 하며, 최소한의 가격 품질 요건을 충족해야 합니다.

## 포함 기준

- 명확한 제안, 결과 및 결제 시간;
- 안정적으로 접근 가능한 시장 가격;
- 목표 상태에 대한 명확한 영향 경로;
- 일관되게 매핑 가능한 방향;
- 현재 구성 요소에 비해 유용한 새로운 정보;
- 검토 주기에 적합한 남은 만기.

## 인과 경로

각 후보 계약에는 다음과 같은 간결한 익스포저 설명이 가능해야 합니다:

> 사건 결과 → 실제 메커니즘 → 목표 상태 변경

메커니즘을 넓은 연관성 이상으로 설명할 수 없는 경우, 해당 사건은 포함되지 않아야 합니다.

## 정보 중복

다른 계약들이 동일한 사실을 반복할 수 있습니다. 모두를 독립적으로 처리하면 하나의 제안을 과장하게 됩니다. 검토에서는 다음을 식별합니다:

- 동일 사건에 대한 다른 만기;
- 동일 결과에 대한 서로 다르게 표현된 시장;
- 동일한 전제 조건에 의존하는 계약;
- 새로운 정보가 거의 없는 지속적으로 유사한 가격.

높이 겹치는 구성 요소는 선택적으로 유지, 결합 또는 가중치를 낮출 수 있습니다.

## 제외 사항

모호한 제안, 불안정한 결제 규칙, 왜곡된 가격, 불충분한 유동성 또는 불확실한 인과 방향은 제외 사유입니다. 단순히 주제 관련성만으로는 자격이 되지 않습니다.
