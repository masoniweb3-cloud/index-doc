# 만료 및 롤링 연속성

**연속 롤링**은 만기가 있는 이벤트 계약과 지속적인 세계 상태 사이의 기간 차이를 해결합니다.

![현재 기간 이벤트는 검토 시점에서 종료되고 다음 기간 이벤트는 진입하며 인덱스 수준은 계속 유지됩니다.](/images/en/07-rolling-continuity-en.png)

## 프로세스

예정된 검토 시점에서:

1. 기존 구성 요소는 최종 유효 기간 계산을 완료합니다;
2. 정산되거나 만료되거나 대표성이 없는 구성 요소가 종료됩니다;
3. 새로운 적격 이벤트가 동일한 목표 상태 정의 하에 진입합니다;
4. 새로운 가중치가 정규화됩니다;
5. 새로운 바스켓은 기존 인덱스 수준에서 계속됩니다.

## 가격 기준

진입하는 각 구성 요소는 정의된 시작 가격을 받습니다. 진입 후의 가격 변화만 계산되며, 이전 시장 움직임은 소급 적용되지 않습니다.

## 기계적 점프 방지

롤링은 기존 바스켓과 새로운 바스켓의 절대 가격을 비교하지 않습니다. 그들의 제안과 확률 수준은 완전히 다를 수 있으므로 직접 연결하면 경제적으로 의미 없는 점프가 발생합니다.

연속성은 인덱스 수준을 이어받음으로써 제공되며, 기존 계약과 새로운 계약의 가격이 동일할 필요는 없습니다.

## 조기 정산 및 무효화

조기 정산되거나 무효화되거나 오래된 구성 요소는 특별 이벤트 규칙을 따릅니다. 발표된 방법론은 마지막 유효 가격, 임시 가중치 재분배, 교체 규칙을 정의해야 합니다.

> 이벤트는 상태가 지속되는 동안 정산되며, 구성 요소가 변경되더라도 인덱스는 연속성을 유지합니다.
