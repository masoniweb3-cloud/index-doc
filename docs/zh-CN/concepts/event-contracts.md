# 事件合约

**一般大家所说的“预测市场”，在 Signa Index 的方法里，就是一份事件合约。**

日常说“某件事开了一个预测市场”，通常指的是：围绕一个具体问题，让参与者买卖不同结果，并在答案确定后结算。

例如：

> 某国会在今年年底前降息吗？

这个市场可以有 YES 和 NO 两个结果。参与者的买卖形成市场价格；到年底后，再按照事先写明的规则确定结果并完成结算。

在 Signa Index 的文档里，我们把这样一个**有明确问题、有市场价格、也会到期结算的具体市场单元**称为事件合约（Event Contract）。

## 为什么使用“事件合约”这个名称？

“预测市场”有时指整个产品或平台，也可能指某一个具体问题。为了在指数计算中说得更准确，Signa 使用“事件合约”指代一份具体、可被纳入指数的市场。

一个事件合约对应一个有限问题；一个 Signa Index 则可能同时使用许多事件合约，共同描述一个长期现实状态。

## 事件合约提供什么信息？

事件合约的价格反映参与者当前如何为某个结果定价。YES 价格上涨，通常表示市场正在提高对该结果的判断；价格下降，则表示市场正在降低这一判断。

Signa Index 使用这种真实市场中可观察的价格变化，而不是由模型独立生成一个概率。

在指数中，事件合约是价格输入，不是指数最终要表达的长期状态。

## 合格事件合约的基本条件

进入指数候选池的合约通常应具备：

- 清晰且可验证的命题；
- 明确的 YES、NO 或其他结果定义；
- 公开的结算依据与截止时间；
- 可持续获得的市场价格；
- 足以支持指数计算的价格质量；
- 与目标状态之间可解释的因果联系。

## YES 不等于正向

YES 只表示“问题中的命题成立”，不一定代表指数要观察的状态变好。

例如，“冲突是否升级”的 YES 价格上升，可能意味着“和平进程”状态减弱。因此，事件合约必须先经过状态方向映射，才能与其他成分共同计算。

## 到期与结算

事件合约具有有限生命周期。合约结算后不再提供新的价格变化，但其所反映的世界状态可能仍在继续。

Signa 通过固定审查和滚动接续更新事件集合，从而将短期合约转换为长期状态序列。
