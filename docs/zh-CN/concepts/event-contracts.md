# 事件合约

**事件合约（Event Contract）**是一类围绕明确现实命题定价，并按照预先规定的结果条件进行结算的合约。

在 Signa Index 中，事件合约是价格输入，不是指数最终要表达的经济标的。

## 事件合约提供什么信息？

事件合约的市场价格反映参与者对特定结果的实时定价。例如，一份 YES 合约的价格变化，可以表达市场对该事件发生可能性的重新判断。

Signa 使用的是这种可观察的价格变化，而不是由模型独立生成的事件概率。

## 合格事件合约的基本条件

进入指数候选池的合约通常应具备：

- 清晰且可验证的命题；
- 明确的 YES、NO 或其他结果定义；
- 公开的结算依据与截止时间；
- 可持续获得的市场价格；
- 足以支持指数计算的价格质量；
- 与目标状态之间可解释的因果联系。

## YES 不等于正向

事件合约的文字方向不能直接作为指数方向。

例如，“冲突是否升级”的 YES 价格上升，可能意味着“和平进程”状态减弱。因此，事件合约必须先经过状态方向映射，才能与其他成分共同计算。

## 到期与结算

事件合约具有有限生命周期。合约结算后不再提供新的价格变化，但其所反映的世界状态可能仍在继续。

Signa 通过固定审查和滚动接续更新事件集合，从而将短期合约转换为长期状态序列。
