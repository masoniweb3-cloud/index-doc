# 世界状态

<strong>世界状态（World State）</strong>是由一系列现实事件共同揭示、跨越单一事件生命周期并持续变化的现实方向。

它不是抽象主题，也不是一组新闻标签。一个合格的世界状态必须满足三个条件：

- **持续性**：状态不会因某一份事件合约结算而终止；
- **方向性**：可以明确判断状态正在增强还是减弱；
- **经济意义**：状态变化能够形成可解释的风险、机会或决策价值。

## 状态与事件的区别

事件是有限命题，状态是长期坐标。

![短期事件合约会分别到期，长期世界状态则持续存在](/images/zh-CN/02-event-vs-state-zh-CN.png)

“双方是否在某日前签署停火协议”是事件；“冲突体系是否由升级转向降级”是状态。前者可以结算，后者会继续受到后续谈判、军事行动和政治安排影响。

## 状态因子

多个事件的市场价格变化可能包含一个共同方向。Signa Index 将这一共同方向视为**状态因子**。

它的作用类似于传统金融中从一组证券收益中识别共同风险因子，但其信息来源不是企业现金流或宏观价格，而是事件结果及事件对现实状态的因果含义。

## 目标状态定义

每个指数都需要一份明确的目标状态说明，至少包括：

1. 状态名称与经济含义；
2. 状态增强和减弱的判断标准；
3. 可接受的事件影响路径；
4. 明确排除的相邻主题；
5. 适用时间范围与审查频率。

这份定义是成分选择、方向映射和指数计算的共同依据。
