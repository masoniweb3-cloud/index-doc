# 状态暴露

<strong>状态暴露（State Exposure）</strong>表示事件结果对目标状态产生影响的有效程度。

它回答的不是“事件有多热门”，而是“事件价格变化中有多少信息真正属于目标状态”。

## 暴露的组成

状态暴露主要由三个维度构成：

- **因果强度**：事件结果与目标状态之间的影响是否直接、明确且重要；
- **信息独立性**：事件是否提供新的状态信息，而不是重复已有成分；
- **价格质量**：市场价格是否具有足够的可观察性、连续性和可靠性。

## 暴露与概率不同

事件发生概率高，不代表状态暴露一定高。

一个几乎确定会发生但对目标状态影响很小的事件，可能只有较低暴露；一个发生概率较低但一旦发生会显著改变目标状态的事件，则可能具有较高暴露。

## 暴露与权重

指数把各成分的状态暴露转换为归一化权重。权重决定每个事件的价格变化对当期指数变化贡献多少。

状态暴露是经济含义，权重是计算表达。两者相关，但不能混为一谈。

## 动态变化

事件的有效暴露可能随时间变化，例如剩余期限缩短、价格质量下降、信息被其他事件吸收或事件已经失去现实影响。

这类变化应在预设审查时点进入权重更新，而不应通过任意的盘中调整改变指数。
