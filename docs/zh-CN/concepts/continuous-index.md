# 连续指数

单一事件合约会在结算后终止，世界状态却会持续演进。**连续指数**通过保持目标状态和计算规则的一致，将不断变化的事件集合连接为一条连续价格序列。

## 连续性的来源

Signa Index 的连续性不依赖永久不变的成分，而来自三个稳定要素：

1. 目标状态定义保持一致；
2. 方向、权重和计算规则保持一致；
3. 成分更换从既有指数点位接续。

## 成分变化不是状态收益

在审查时点加入或移除事件，只是更新用于观察状态的工具集合，不应被当作目标状态本身发生了变化。

因此，新成分从新的有效周期开始贡献价格变化，成分替换本身不制造指数跳变。

## 可比较性

连续序列使使用者能够观察：

- 某个状态在不同时间的方向变化；
- 市场重定价的速度与幅度；
- 不同状态指数之间的相对表现；
- 与现实事件时间线之间的关系。

## 连续不代表无变化

指数方法可以更新，但任何影响历史可比性的变更都需要记录、生效日期和版本说明。重大方法变化可能需要新指数版本，而不是直接改写历史序列。
