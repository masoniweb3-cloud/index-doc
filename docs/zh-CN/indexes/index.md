# 指数体系

Signa Index 是一套围绕不同世界状态构建的指数体系，而不是单一指数。

每个指数拥有独立的目标状态定义、合格事件范围、方向映射、权重规则和审查日历，同时共享世界状态指数的基础方法框架。

## 当前分类框架

### 国家发展

描述一个国家或经济体在增长能力、制度执行、产业升级和长期发展势能上的状态变化。

[了解国家发展类指数 →](./country-development)

### 地缘秩序

描述冲突、合作、联盟、谈判和区域稳定安排所共同形成的国际秩序状态。

[了解地缘秩序类指数 →](./geopolitical-order)

### 政治权力

描述政治主体获得、维持、转移或失去制度性权力的状态变化。

[了解政治权力类指数 →](./political-power)

### 技术演进

描述关键技术从研究突破走向部署、扩散、治理与社会采用的状态变化。

[了解技术演进类指数 →](./technology-evolution)

## 分类不是指数

上述页面定义的是指数家族的经济边界，不代表具体指数已经发布。

一个可发布指数还需要单独披露：

- 正式名称与标识；
- 目标状态和方向；
- 基准日期与基准点位；
- 数据来源与价格规则；
- 成分选择和权重方法；
- 计算频率与审查日历；
- 异常事件处理；
- 当前方法版本与历史变更。
