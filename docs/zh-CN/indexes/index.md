# 首发指数

Signa Index 初版围绕六个现实主题构建指数。每个主题都有正向和反向两个独立方向：正向用于表达主题状态增强，反向用于表达主题状态减弱。

下面的事件仅用于帮助理解方向，不代表当前实时成分。实际点位、成分和交易状态以 Signa 产品页面为准。

| 指数 | 正向指数通常在什么情况下上涨 | 反向指数通常在什么情况下上涨 |
| --- | --- | --- |
| **中东和平指数** | 停火持续、谈判推进、人质释放、外交正常化或冲突降级 | 战争延续、军事升级、谈判失败或冲突扩散 |
| **中国国运指数** | 经济韧性、科技能力、国际影响力、政策稳定性或外部安全改善 | 上述维度出现明显恶化或重大外部压力 |
| **美国国运指数** | 经济韧性、科技领导力、制度运行、政策执行或国际影响力改善 | 衰退风险、制度冲突、科技领导力或国际影响力减弱 |
| **欧洲国运指数** | 经济与货币韧性、能源安全、产业竞争力、一体化或国际影响力改善 | 经济、能源、产业、一体化或外部安全环境恶化 |
| **AI 发展指数** | 模型能力、算力、产业落地、投资或有利于发展的治理环境进步 | 能力进展停滞、算力受限、投资收缩、落地受挫或监管显著收紧 |
| **加密货币发展指数** | 采用扩大、监管更明确、机构参与增加、基础设施成熟或主流金融整合 | 采用萎缩、监管打压、机构退出或重大安全与信任危机 |

::: info 如何理解这些例子
指数不会因为出现一条相关新闻就机械上涨或下跌。事件必须进入当前成分，并经过方向映射和权重计算，其市场价格变化才会影响指数。
:::

## 不是 YES 与 NO

正向和反向指数不是一份二元合约的 YES 与 NO。两者各自拥有连续点位，不要求相加等于 100。选择反向指数也不是“卖出正向指数”，而是买入同一主题的另一种方向持仓。

## 查看与交易

具体指数的当前点位、正向/反向方向、实时成分、报价和可用状态，以 [Signa 官网](https://signaindex.com/) 展示为准。

想了解指数为何会持续更新，可阅读[到期与滚动接续](/zh-CN/methodology/rolling)；想了解买卖方式，可阅读[如何交易](/zh-CN/guide/trading)。
