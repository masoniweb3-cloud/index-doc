# 技术演进类指数

技术演进类指数衡量一项关键技术从研究突破走向部署、扩散、治理和社会采用的持续状态。

它不是科技公司股票指数，也不直接衡量企业估值。事件成分必须通过技术能力、可用性、采用或制度环境影响目标状态。

## 可能的状态维度

- 核心技术能力突破；
- 商业部署和规模化能力；
- 成本下降与基础设施成熟；
- 用户、企业或公共部门采用；
- 法规许可、限制和治理框架；
- 安全事件与社会信任。

## 候选事件示例

技术基准突破、关键产品发布、重大审批、基础设施里程碑、行业采用目标或具有系统性影响的安全事件，都可能成为候选成分。

## 时间范围

技术事件的短期市场反应与长期扩散影响可能不同。指数必须预先确定主导时间范围，避免在方向判断中混合短期竞争结果和长期技术演进。

> 本页描述指数家族框架，不代表具体技术演进指数已经正式发布。
