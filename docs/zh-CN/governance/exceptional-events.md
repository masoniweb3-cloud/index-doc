# 异常事件

异常事件是正常审查日历无法充分处理、并可能影响指数可计算性或代表性的情况。

## 常见类型

- 数据源中断或严重延迟；
- 事件市场暂停、关闭或失去有效价格；
- 合约提前结算、作废或结算争议；
- 合约条款发生实质变化；
- 极端价格异常或明显错误数据；
- 现实事件使既有因果路径失效；
- 关键基础设施或计算流程中断。

## 处理原则

异常处理应优先使用预先公布的规则，并遵循：

1. 尽可能维持计算连续性；
2. 不创造没有经济含义的指数跳变；
3. 不根据预期收益选择处理方案；
4. 最小化对未受影响成分的改动；
5. 及时记录并披露处理过程。

## 可能的处理方式

根据具体指数规则，可以使用最近有效价格、临时冻结成分、按规则重新分配权重、移除失效成分或启动临时再平衡。

如果指数已无法合理代表目标状态，可以暂停发布，而不是继续产生误导性点位。

## 事后复核

重大异常结束后应评估现有规则是否充分，并决定是否需要前瞻性方法更新。规则更新不应自动改写已经发布的历史处理结果。
