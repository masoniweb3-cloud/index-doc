# 指数治理

指数治理确保目标状态、成分映射、数据处理和规则变更按照一致标准执行。

治理的目标不是消除所有判断，而是使重要判断具有明确职责、可审查依据和完整记录。

## 治理范围

- 批准新的目标状态和指数方法；
- 审查成分选择、方向冲突和权重约束；
- 监督数据质量与异常事件处理；
- 批准重大规则变更；
- 管理模型版本和人工覆盖；
- 发布审查、版本和更正记录。

## 核心原则

### 独立于结果

方法决策不应因为某种价格表现或现实结果更受欢迎而改变。

### 事前规则

可预见的情况应在方法文件中提前规定，减少事件发生后的任意裁量。

### 职责清晰

数据采集、AI 映射、方法审批和发布应有明确责任边界。

### 可追溯

重大判断、异常处理和规则变更应保留时间、理由、版本和批准记录。

## 指数级文件

每个正式指数应拥有独立方法文件和变更记录。体系级原则不能替代具体指数的参数披露。
