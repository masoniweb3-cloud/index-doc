# 方法变更

方法变更用于修复缺陷、提高数据可靠性或适应事件市场结构变化，但不能被用于追求特定历史表现。

## 变更等级

### 编辑性变更

修正文案、链接或不影响计算含义的说明。可以直接发布，但仍应记录版本。

### 非重大方法变更

改进操作细节，但不改变目标状态或指数主要风险暴露。例如更明确的时间戳规则。

### 重大方法变更

改变目标状态、主要数据来源、方向规则、权重框架、计算公式或历史可比性的变更。

重大变更应经过正式评估，并在生效前说明原因、影响和过渡方式。

## 变更记录

每项方法变更至少记录：

- 变更内容和原因；
- 受影响的指数与规则；
- 对历史和未来序列的影响；
- 生效日期；
- 兼容性和迁移说明；
- 批准人和方法版本。

## 历史数据

除明确的数据错误更正外，不应使用新方法任意重算历史序列。需要回溯时，应同时保留原版本、重算范围和差异说明。
