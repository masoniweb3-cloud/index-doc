# 成分选择

指数成分来自可观察的真实事件合约。候选合约必须与目标状态存在可说明的实质性因果联系，并满足最低价格质量要求。

## 纳入条件

一个事件通常需要同时满足以下条件：

- 命题、结果条件和结算时间明确；
- 市场价格可稳定获取；
- 事件结果对目标状态存在清晰影响路径；
- 影响方向能够被一致映射；
- 与现有成分相比提供有效的新信息；
- 剩余期限适合当前指数审查周期。

## 因果路径

每个候选事件都应形成一条简明的暴露说明：

> 事件结果 → 现实机制 → 目标状态变化

如果中间机制无法说明，或只能依赖宽泛联想，事件不应进入指数。

## 信息重叠

多个合约可能用不同表述重复同一事实。如果全部按独立信息纳入，会放大单一命题的影响。

成分审查需要识别：

- 相同事件的不同截止日期；
- 同一结果的不同市场表述；
- 高度依赖同一前置事件的合约；
- 价格走势长期近似且缺乏新增信息的合约。

对于高度重叠的成分，可以择优保留、合并暴露或降低权重。

## 排除情形

命题含糊、结算规则不稳定、价格长期失真、流动性不足或因果方向无法确定的事件，不进入指数。事件即使主题相关，也不构成自动纳入理由。
