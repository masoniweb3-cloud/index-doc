# 到期与滚动接续

**滚动接续（Rolling Continuity）**解决事件合约有限期限与世界状态长期持续之间的期限错配。

![当前周期事件退出、下一周期事件进入审查时点，而连续指数点位保持接续](/images/zh-CN/07-rolling-continuity-zh-CN.png)

## 基本流程

在预定审查时点：

1. 旧成分按当前规则完成最后一个有效周期的价格计算；
2. 已结算、即将到期或失去代表性的成分退出；
3. 新的合格事件按照同一目标状态定义进入；
4. 新权重完成归一化；
5. 新组合从现有指数点位继续计算。

## 价格基准

新成分进入时，需要记录明确的初始价格基准。指数只计算其进入后的价格变化，不把进入前已经发生的市场变化追溯计入指数。

## 避免机械跳变

滚动时不直接比较旧组合和新组合的绝对事件价格。两组事件可能具有完全不同的命题和概率水平，直接拼接会产生没有经济含义的跳变。

连续性通过指数点位接续实现，而不是通过要求新旧合约价格相等实现。

## 提前结算和作废

对于提前结算、作废或价格停止更新的成分，应按照指数的异常事件规则处理。正式方法文件需要说明最后有效价格、临时权重再分配和替代成分规则。

> 事件可以结算，状态持续存在；成分不断变化，指数保持连续。
