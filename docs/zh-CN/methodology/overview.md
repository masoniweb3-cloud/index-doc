# 构建流程

Signa Index 的构建目标，是把动态变化的事件合约集合转换为定义一致、计算可复现、时间连续的世界状态指数。

## 构造流程

完整流程由六个环节组成：

1. **定义目标状态**：确定指数试图衡量的持续性现实方向；
2. **选择事件合约**：识别与目标状态具有实质因果联系的合约；
3. **统一事件方向**：将不同合约结果映射为状态增强或减弱；
4. **确定状态暴露**：评估因果强度、信息独立性与价格质量；
5. **聚合状态重定价**：计算方向调整后的加权价格变化；
6. **审查与滚动接续**：更新成分，同时保持指数点位连续。

## 构建原则

### 因果优先

事件能否进入指数，取决于其结果是否能够通过清晰路径改变目标状态，而不是关键词是否相似。

### 方向一致

所有成分必须映射到同一个状态坐标，使不同事件的价格变化具有一致金融含义。

### 暴露而非热度

权重反映事件对目标状态的有效暴露，不直接等同于交易量、媒体关注或主观重要性。

### 连续但不僵化

目标状态和计算规则保持一致，成分则随事件生命周期和信息环境动态更新。

### 可解释与可复现

每次成分纳入、方向判断、权重分配和规则变更，都应具有可记录的依据。
