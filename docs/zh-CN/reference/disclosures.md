# 产品规则与声明

本文件说明 Signa Index 文档、指数数据和当前指数份额产品的一般使用边界。具体参与资格、订单和资金操作还受产品页面展示的适用规则约束。

## 信息性质

文档用于解释世界状态指数、六个首发主题、交易方式和使用边界。首发指数页面中的事件仅为方向示例，不代表实时成分、实时点位或可执行报价。

## 非概率声明

指数点位不是单一事件的发生概率，也不应被解释为对现实结果的确定性预测。

## 非完整现实描述

任何世界状态指数都依赖有限事件集合和明确方法边界。它无法捕捉现实中的全部信息，也可能受到数据、市场结构和映射判断限制。

## 非专业建议

指数、文档和相关数据不构成投资、交易、法律、税务、会计或政策建议，也不保证任何结果或收益。

## 指数份额的性质

当前指数份额是记录在 Signa 用户账户中的交易持仓，不是发送到用户钱包的 BEP-20 代币，不能在用户之间自由转让，也不能作为指数份额直接提现。用户需要先卖出份额换回 USDT，再提现可用 USDT。

指数点位本身不是概率，也不是天然以 USDT 计价的资产价格。实际份额、买卖金额和费用以有效产品报价及订单回执为准。

## 托管与可用性

用户充值确认后，USDT 由 Signa 托管，账户余额和持仓由平台账本记录。这不是全程自托管模式。多重校验、分离控制和账本记录用于降低特定风险，但不构成存款保险或绝对安全保证。

指数持续计算不代表产品始终可以交易。数据异常、报价过期、流动性不足、区块链故障、平台保护机制或其他风险事件都可能造成充值、交易或提现暂停、延迟。

## 费用和规则变更

当前公开规则包括 1% 买入开仓费和 0% 卖出平仓费。提现手续费、最低金额、订单限额和区块确认要求以操作页面显示为准，并可能随产品规则更新。已经完成的历史订单保留成交时的实际记录。
