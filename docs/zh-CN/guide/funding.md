# 充值与提现

Signa 当前使用 **BNB Smart Chain（BSC，Chain ID 56）** 上的 **USDT（BEP-20）** 处理用户充值和提现。

::: info 资金如何安全保管
每个账户使用专属 BSC 地址识别充值。系统校验网络、USDT 合约、收款地址、金额和区块确认后，才会将资金记入你的可用余额。入账后的 USDT 进入 Signa 安全托管体系，由隔离的托管服务、分离密钥和可对账账本统一管理。提现仅发送至与账户对应的 BSC 钱包，并需要钱包再次签名确认。
:::

::: danger 不要跳过这一条
只能向充值地址发送页面指定的 BSC USDT。发送其他代币，或从 Ethereum、Polygon、Tron 等其他网络发送，都可能造成永久损失。
:::

## 如何充值

1. 登录后打开“充值”。
2. 核对网络为 **BNB Smart Chain（BEP-20）**，并核对页面显示的 USDT 代币合约。
3. 选择一种方式：
   - 在页面输入金额，直接调起当前连接钱包；
   - 复制或扫描系统为你分配的专属 BSC 充值地址，再从其他钱包转入。
4. 确认金额不低于页面显示的“最低充值”。
5. 发起交易后，等待状态从“已提交”、“已检测”变为“已入账”。

从已连接钱包充值时，钱包还会显示一笔 BNB Gas 费。这笔费用支付给 BSC 网络，不是 Signa 的 1% 开仓费。

### 低于最低充值会怎样？

当前系统会记录低于最低额的链上转账，但不会将其记入交易余额，也不承诺自动找回。最低金额可能调整，以充值页面的当前值为准。

## 什么时候入账？

钱包显示“已发送”不等于 Signa 已入账。系统需要：

1. 在 BSC 上检测到正确的 USDT Transfer；
2. 核对收款地址、代币合约和金额；
3. 等待页面显示的所需确认数；
4. 将资金记入你的可用交易余额。

充值记录会显示交易哈希、确认进度和最终状态。

## 如何提现

1. 打开“提现”，确认可提现余额。
2. 输入金额，页面会显示最低额、单笔上限、UTC 每日上限、手续费和预计到账金额。
3. 确认目标地址。当前提现只会发回与登录账户对应的 BSC 钱包。
4. 在钱包中签署提现授权。签名用于确认金额、手续费、目标地址和一次性随机数，不会把私钥交给 Signa。
5. 提交后在“最近提现”中查看处理中、已提交 BSC 或已完成等状态。

## 处理中的提现

申请提交后，对应金额会先从可用余额中预留。提现失败或被退回时，预留金额会返回账户可用余额。在最终状态确定前，不要根据钱包提示或单一区块浏览器页面重复提交。

::: tip 数值以页面为准
最低充值、提现限额、提现手续费和所需确认数都可能更新。提交任何资金操作前，以 Signa 产品页面实时显示的规则为准。
:::
