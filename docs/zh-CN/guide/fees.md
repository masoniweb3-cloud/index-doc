# 费用说明

## 1% 到底是什么？

当前产品的 **1% 是买入开仓费**。它在用户买入并创建指数份额时收取，与用于计算份额的本金分开列示。

它不是：

- 不是根据盈利收取的“收益税”；
- 不是充值的 BSC Gas 费；
- 不是提现手续费；
- 不会直接改变指数点位。

### 买入示例

假设用户输入 **100 USDT** 作为买入本金，开仓费率为 1%：

| 项目 | 金额 |
| --- | ---: |
| 用于计算指数份额的本金 | 100 USDT |
| 1% 开仓费 | 1 USDT |
| 总支付 | 101 USDT |

账户可用余额至少需要覆盖总支付金额，而不只是买入本金。

## 卖出收费吗？

按当前产品规则：

- 开仓费只在买入时收取；
- 卖出的平仓费为 **0%**；
- 卖出报价显示的卖出总额，就是当前规则下预计记入可用余额的金额。

历史订单会保留成交当时的实际费用记录，不会因后续规则变更而重写。

## 还有哪些费用？

### BSC Gas 费

从已连接钱包向专属充值地址发送 USDT 时，钱包需要支付 BNB Gas 费。该费用由 BSC 网络收取，金额随网络状态变化。

### 提现手续费

提现可以设置固定手续费。页面会在签名前显示：

- 账户扣减总额；
- 提现手续费；
- 钱包预计到账额。

提现金额必须高于手续费。具体费用以提现页的当前策略为准。

::: warning 报价是最终确认依据
费率和运营规则可能调整。每次买入、卖出或提现前，都应以确认页显示的费率、实际金额和有效期为准。
:::
