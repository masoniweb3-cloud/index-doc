# 开始使用 Signa Index

Signa Index 把同一现实主题下的多个预测市场合成为连续指数。在当前产品中，用户可以用 USDT 买入某个主题的正向或反向指数份额，并在之后卖出已持有的份额。

## 使用前先知道这五件事

1. **当前使用 BNB Smart Chain（BSC）。** 充值和提现资产为 BSC 上的 USDT（BEP-20）。
2. **每个主题都有两个方向。** 正向跟随主题走势，反向与主题反向变动。
3. **买入是建立持仓，卖出是减少持仓。** 卖出不会自动建立反向仓位；要表达相反观点，需要买入反向指数。
4. **当前 1% 是买入开仓费。** 它不是“盈利税”，也不是卖出手续费；当前卖出不收平仓费。
5. **充值后资金进入 Signa 托管账户体系。** 交易使用平台内部账户余额，不是资产全程留在你的钱包中。

## 一次完整流程

### 1. 登录并准备资金

连接支持 BSC 的钱包并完成签名登录。如果当前部署显示 Google 登录，也可用 Google 账号进入同一套账户与交易体系，但直接调起钱包充值和提现仍有额外限制。从当前钱包充值时，还需要少量 BNB 支付链上 Gas 费。

### 2. 充值 BSC USDT

打开“充值”，可以直接从已连接钱包发送，也可复制系统为你分配的专属 BSC 充值地址。交易达到所需确认数后，USDT 会记入可用交易余额。

### 3. 选择主题和方向

先判断你关心的现实主题会增强还是减弱，再选择正向或反向指数。两个方向都有自己的指数点位，不是必须相加等于 100 的 YES/NO 价格。

### 4. 获取报价并确认买入

输入 USDT 金额后，系统会显示指数参考点位、预计份额、开仓费和总支付金额。服务端报价只在倒计时内有效，超时后需要刷新。

### 5. 查看持仓或卖出

成交后，可在“持仓”查看份额、平均买入价、当前价值和未实现盈亏。卖出时只能减少当前账户已有的份额。

### 6. 提现

卖出后的可用 USDT 可申请提现至当前登录钱包。提现前需要再次签名确认金额、手续费和目标地址。
