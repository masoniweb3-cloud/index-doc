# 充提问题排查

充值或提现长时间没有完成时，先不要重复发送资金或重复提交申请。链上确认、网络拥堵和状态同步都可能需要时间，重复操作反而可能让问题更难核对。

## 充值没有入账

依次检查：

1. 转账网络是否为 **BNB Smart Chain（BSC，Chain ID 56）**；
2. 发送的资产是否为充值页指定的 **USDT（BEP-20）**；
3. 收款地址是否与当前账户的专属充值地址完全一致；
4. 金额是否达到页面显示的最低充值额；
5. 区块浏览器是否已经显示交易成功；
6. 页面是否仍在等待所需确认数。

低于最低额、发错网络、发错代币或发往错误地址的转账，不承诺能够自动找回。

## 提现一直处理中

“处理中”表示对应金额已经从可用余额中预留，但链上最终结果尚未确定。此时：

- 不要重复提交同一笔提现；
- 不要只根据钱包通知判断成功或失败；
- 如果页面已经显示交易哈希，可在 BSC 区块浏览器查看确认进度；
- 网络超时或广播状态不明确时，余额不会立即退回，以避免重复支付。

只有系统确认交易尚未发送，或链上已经确认最终失败后，预留金额才会退回可用余额。

## 请求核查时准备什么？

通过 Signa 官网公布的官方支持渠道请求核查时，请提供：

- 登录钱包地址；
- BSC 交易哈希；
- 充值或提现金额；
- 大致发起时间和时区；
- 页面显示的当前状态；
- 必要时附上不包含敏感信息的页面截图。

::: danger 永远不要提供这些信息
Signa 不会要求你提交私钥、助记词、钱包密码或远程控制设备。任何索要这些信息的人都不应被信任。
:::
