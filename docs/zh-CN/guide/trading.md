# 如何交易

Signa 的交易对象是记录在用户账户中的指数份额。买入时，你用 USDT 建立某个主题、某个方向的持仓；卖出时，你把已有份额按当前报价换回 USDT。

::: info 指数份额不是链上代币
指数份额不会发送到你的钱包，目前不能转给其他用户，也不能作为指数份额直接提现。退出持仓时，需要先卖出份额换回 USDT，再提现可用 USDT。
:::

## 先选主题，再选方向

每个主题都提供两个独立方向：

| 你的判断 | 选择 | 典型表现 |
| --- | --- | --- |
| 目标状态将增强 | 正向指数 | 成分市场更支持该主题时上升 |
| 目标状态将减弱 | 反向指数 | 成分市场更不支持该主题时上升 |

例如，对“和平进程”主题，如果你认为停火、谈判等事件的整体定价会越来越有利于和平状态，可选正向；如果认为该状态会减弱，可选反向。

::: info 反向不等于“卖出”
“卖出”只是减少你已经持有的份额。如果你没有持仓，不能通过点击卖出建立空头。要获得相反方向的价格暴露，应买入对应的反向指数。
:::

## 买入步骤

1. 打开一个主题，选择正向或反向。
2. 在交易面板选择“买入”，输入投入的 USDT 本金。
3. 查看预估份额、指数参考点位、开仓费和总支付金额。
4. 获取服务端报价。报价会同时锁定指数价格、开仓费、指数版本和有效期。
5. 在倒计时内确认订单。报价过期后，需要重新获取。
6. 成交后在“持仓”和“记录”查看份额与订单回执。

## 卖出步骤

1. 在交易面板选择“卖出”，或从“持仓”中打开快捷卖出。
2. 选择要减少的持仓，输入份额，也可选择 25%、50% 或全部卖出。
3. 查看卖出总额、平仓费和预计收到的 USDT。页面显示的是当前可获得的产品报价，不是对未来退出价格的保证。
4. 获取并在有效期内确认服务端报价。
5. 成交后，已卖份额从持仓中减少，USDT 记入可用余额。

当前只能卖出登录账户真实持有的份额，不允许超额卖出。

## 为什么有时不能交易？

遇到以下情况时，系统会暂停新报价或订单：

- 最新指数价格不可用或过时；
- 交易、订单路由或交易后处理系统未就绪；
- 交易安全条件不满足，系统暂时关闭新订单；
- 订单金额低于最低额、超过最高额，或买入总额超过可用 USDT；
- 卖出份额超过当前持仓。

这种情况下，已有持仓和历史订单仍可查看。不可用的指数价格不会被当作 0 处理。

## 报价和指数点位有什么区别？

指数点位用于记录主题状态变化，本身不是一枚以 USDT 计价的链上代币。产品使用当前指数参考点位计算买入份额和卖出金额，并生成有有效期的服务端报价。

只有订单确认页中的有效报价可以用于成交。页面上的历史点位、走势图或已经过期的报价，都不代表用户一定能够按该数值买入或卖出。
