# 指数与挂钩产品

Signa Index 是规则化计算的金融基准。以指数点位或收益为参考，可以进一步设计指数挂钩产品，但指数与产品必须清晰区分。

![指数层定义目标状态、成分、方向、权重和点位，产品层独立规定期限、费用、流动性与风险](/images/zh-CN/09-index-vs-linked-product-zh-CN.png)

## 指数层

指数层负责：

- 定义目标状态；
- 选择和维护事件成分；
- 统一状态方向；
- 计算权重和指数点位；
- 发布方法、数据和版本记录。

指数本身不自动代表任何具体投资、代币、存款或收益承诺。

## 产品层

指数挂钩产品可能使用指数的点位、单期收益或其他经过定义的指标作为参考或结算依据。

产品还需要独立规定：

- 发行方或合约主体；
- 期限和结算方式；
- 抵押、保证金或资金安排；
- 费用和融资成本；
- 流动性和退出机制；
- 法律、地区与参与资格；
- 产品特有的风险披露。

## 为什么必须区分？

同一指数可以被不同产品引用，而不同产品的实际收益和风险可能明显不同。

指数表现良好不保证挂钩产品获得相同回报；产品费用、跟踪误差、交易条件和对手方安排都会影响最终结果。
