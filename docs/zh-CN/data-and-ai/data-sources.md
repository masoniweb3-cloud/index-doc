# 数据来源

Signa Index 的基础价格输入来自可观察的真实事件合约市场。数据来源必须能够支持稳定采集、历史重现和明确的时间记录。

## 需要采集的数据

对于每份候选事件合约，至少需要记录：

- 市场与合约标识；
- 原始命题文本和结果选项；
- 结算条件、截止时间和状态；
- 价格及对应时间戳；
- 可用的成交、流动性或价差信息；
- 数据源和抓取版本；
- 后续更正、作废或结算记录。

## 价格选择

正式指数方法需要规定使用的价格类型，例如可执行中间价、最后成交价、时间加权价格或其他经过验证的参考价格。

价格选择应降低偶发成交、短时价差扩大或单点异常对指数的影响，同时保持规则可复现。

## 时间一致性

不同市场的更新时间、时区和暂停状态可能不同。指数计算必须使用统一时间标准，并明确价格截点、缺失数据和延迟数据的处理方式。

## 多来源事件

同一事件可能在多个市场交易。是否合并多来源价格、选择主要市场或建立来源优先级，应由指数规则事先确定。

数据来源变化需要记录，不能在没有披露的情况下用新来源改写历史输入。
