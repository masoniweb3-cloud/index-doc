# Signa Index 如何运作？

Signa Index 将自然语言事件、预测市场价格和指数计算规则连接为一条完整链路。

![世界状态指数从目标定义、事件选择、方向统一和暴露加权，到价格聚合与滚动接续的六步构造流程](/images/zh-CN/03-index-construction-flow-zh-CN.png)

## 1. 定义目标状态

首先定义一个具有持续性、方向性和经济意义的目标状态，并明确什么代表状态增强，什么代表状态减弱。

目标状态是全部成分判断的共同坐标。没有清晰的状态定义，就无法一致地判断事件方向和有效暴露。

## 2. 识别相关事件

系统从真实预测市场中识别与目标状态具有实质因果联系的事件合约。候选事件必须回答一个问题：

> 这个事件的结果，将通过什么路径改变目标状态？

关键词相似、新闻热度或主题相关性本身不足以成为纳入依据。

## 3. 统一状态方向

事件合约中的 YES 和 NO 只是合约文字方向，并不天然等于对目标状态的看多或看空。每个事件都必须被转换到统一坐标：

- 有利于目标状态增强的结果记为正向；
- 有利于目标状态减弱的结果记为反向。

## 4. 建立状态暴露权重

权重表示事件对目标状态的有效暴露，主要综合因果强度、信息独立性和价格质量。权重归一化后，构成指数在该周期的完整状态暴露。

## 5. 聚合价格变化

指数聚合所有成分经过方向调整后的价格变化，并将结果连续复合到上一期点位。当市场整体提高对正向状态的定价时，正向指数上升；反之则下降。

## 6. 滚动接续

事件合约会到期，世界状态不会。指数在固定审查时点移除已到期或失效的事件，并纳入新的合格事件，从同一指数点位继续计算。

> 事件可以结算，状态持续存在；成分不断变化，指数保持连续。
