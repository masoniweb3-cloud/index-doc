# Signa Index 如何运作？

Signa Index 的工作，可以概括为一句话：先说清楚要观察什么，再把真正相关的事件放到同一个方向上，最后将它们合成为一条连续指数。

下面继续用“和平进程指数”作为例子。

![世界状态指数从目标定义、事件选择、方向统一和暴露加权，到价格聚合与滚动接续的六步构造流程](/images/zh-CN/03-index-construction-flow-zh-CN.png)

## 1. 先说清楚要观察什么

“和平”这个词太宽泛。指数必须先明确：它观察的是冲突体系从升级走向降级、谈判恢复和稳定安排逐步形成的过程。

同时还要写清楚什么代表改善、什么代表恶化。这个定义是后续所有事件判断的共同标准，在指数构建中称为**目标状态**。

## 2. 找到真正会影响它的事件

接下来，从预测市场中寻找可能改变和平进程的事件，例如停火、谈判、军事升级、制裁变化和第三方调解。

每个候选事件都必须回答一个问题：

> 这个事件的结果，将通过什么路径改变目标状态？

仅仅出现相似关键词，或者最近很热门，并不足以进入指数。必须能说明它为什么会让和平进程改善或恶化。

## 3. 把相反的事件放到同一方向

不同合约的价格上涨，可能代表完全相反的含义：

- 停火概率上涨，通常代表和平进程改善；
- 军事升级概率上涨，通常代表和平进程恶化。

Signa 会把这些事件转换到统一坐标：有利于目标状态的变化记为正向，不利于目标状态的变化记为反向。这样，不同文字方向的市场价格才可以共同计算。

## 4. 判断每个事件有多重要

一份覆盖核心停火协议的市场，通常比一场象征性会面的市场更能改变和平进程；一个交易连续、价格可信的市场，也比长期无人参与的市场提供更多有效信息。

因此，Signa 不会让所有事件平均分配影响力，而是综合判断：

- 事件对目标状态的影响是否直接且重要；
- 它是否提供了新的信息，而不是重复其他事件；
- 市场价格是否连续、可观察且具有足够质量。

这些判断形成事件的**状态暴露权重**。

## 5. 合成指数变化

指数聚合所有事件经过方向调整和权重处理后的价格变化。

当多个重要市场共同指向和平进程改善时，指数上升；当市场开始提高对冲突升级的定价时，指数下降。

指数关注的是市场判断发生了怎样的变化，而不是把各事件当前的概率直接求平均。

## 6. 旧事件结束后，换入新事件

停火谈判会结束，新的谈判和新的冲突事件还会出现。Signa 会在审查时点移除已经结算、即将到期或失去代表性的事件，再按照同一标准纳入新的事件。

新组合从原有指数点位继续计算，不会因为换了一批事件就重新从零开始。这个过程称为**滚动接续**。

## 最终得到什么？

最终结果不是“某件事会不会发生”的单一概率，而是一条持续反映市场如何重新判断某个现实状态的指数曲线。

> 事件可以结算，状态持续存在；成分不断变化，指数保持连续。
