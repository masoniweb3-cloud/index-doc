# 为什么需要世界状态指数？

预测市场擅长回答具体问题：某项法案会不会通过、某次谈判会不会达成协议、某个产品会不会按时发布。

但人们真正关心的，往往不是某一个事件，而是事件背后的长期变化。

| 单个事件回答的问题 | 人们真正想了解的状态 |
| --- | --- |
| 停火协议会不会签署？ | 和平进程是在改善还是恶化？ |
| 某项关键法案会不会通过？ | 一个国家的发展势能是否增强？ |
| 某个产品会不会按时发布？ | 一项技术是否正在加速普及？ |
| 某位候选人会不会赢得选举？ | 一个政治力量是否正在扩大？ |

单个市场能给事件定价，却很难独自回答右边这些问题。

## 单个事件只是一块拼图

和平进程不会由一次停火决定，技术普及也不会由一次产品发布决定。重要的现实趋势通常同时受到许多事件影响，每个事件只揭示其中一部分。

如果只看一个市场，读者很容易把局部变化误认为整体趋势。

## 状态不会随一份合约到期

事件合约有明确的截止时间。结果确定后，市场结算并结束。

但和平进程、国家发展和技术演进不会因为一份合约结算就停止。新的谈判、新的政策和新的里程碑会继续出现。

这就产生了一个期限错配：用会到期的事件市场，观察不会到期的现实趋势。

## 不同事件的“上涨”含义可能相反

“停火概率上升”通常意味着和平进程改善；“军事升级概率上升”却意味着和平进程恶化。虽然两份合约的价格都在上涨，它们对同一状态的含义正好相反。

因此，相关市场不能直接放在一起求平均。必须先统一方向，再判断每个事件对目标状态有多重要。

## Signa Index 解决的问题

Signa Index 把这些分散、短期、方向不一的事件信号组织起来：

- 找出真正会影响目标状态的事件；
- 把正向和反向事件转换到同一方向；
- 让影响更直接、信息质量更高的事件占更大权重；
- 在旧事件结束后接入新事件，让指数继续运行。

最终得到的不再是一个孤立事件的概率，而是一条持续记录现实状态变化的指数曲线。

## 它带来了什么？

研究者可以观察市场对长期趋势的判断如何变化，指数产品可以引用同一套公开规则，使用者也可以围绕同一状态表达正向或反向观点。

预测市场为一个个事件定价；Signa Index 把这些事件组织成一条现实趋势。
