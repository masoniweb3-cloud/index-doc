# 为什么需要世界状态指数？

传统市场能够交易公司、商品、利率和货币，却很难直接表达“和平进程是否改善”“某国发展势能是否增强”或“某项技术是否加速进入主流”等现实方向。

预测市场补上了一部分缺口：它能为一个明确事件的结果定价。但单一事件具有三个天然限制：命题离散、期限有限、结算后消失。

## 状态不会随一份合约到期

现实状态通常存在于一系列相互关联的事件之中。每个事件都是一次局部显现，而不是状态本身。

例如，“和平进程”可能同时受到停火、谈判、军事升级、制裁变化与第三方调解的影响。任何一份合约都无法独立承载这条长期方向。

## Signa Index 解决的问题

世界状态指数通过统一方法处理这种期限错配：

- 将不同文字方向的事件转换为一致的状态方向；
- 按事件对目标状态的有效暴露分配权重；
- 聚合市场对状态的连续重定价；
- 在旧事件结算后纳入新事件，使指数持续存在。

最终得到的不再是一个孤立问题的概率，而是一条可以观察、比较和引用的状态价格序列。

## 新的金融表达能力

Signa Index 使原本无法直接持有的现实方向获得标准化表达。研究者可以观察状态变化，产品可以引用指数作为基准，风险承担者则可以围绕同一状态建立正向或反向敞口。
