# 什么是 Signa Index？

**Signa Index 把多个围绕同一现实主题的预测市场，合成为一条持续更新的指数。**

比如，要判断一个地区的和平进程是在改善还是恶化，只看“是否会签署停火协议”这一份预测市场并不够。谈判是否重启、军事行动是否升级、制裁是否解除、第三方调解是否取得进展，都会影响和平进程。

这些事件各自回答一个具体问题。Signa Index 将它们放到同一个方向上，形成一条能够持续反映和平进程变化的指数。

如果股票指数用多家公司的股价描述一组公司的整体表现，那么 Signa Index 用多个事件合约的价格，描述一个现实状态的整体变化。

## 什么是“世界状态”？

世界状态，是无法由一个事件完整描述、但会被一系列事件共同推动的长期现实方向。例如：

- 一个国家的发展势能是在增强还是减弱；
- 一个地区的地缘局势是在缓和还是恶化；
- 一项技术是在加速普及还是失去动力；
- 一个政治力量是在扩大还是收缩。

单个事件会发生、结束和结算，但这些状态仍会继续变化。

## Signa 怎么把事件变成指数？

Signa 会完成四件事：

1. 找出真正会影响目标状态的事件；
2. 判断事件结果代表状态增强还是减弱；
3. 根据事件的重要性和市场质量分配权重；
4. 在旧事件结束后接入新事件，保持指数连续。

因此，Signa Index 不是事件概率的简单平均，而是市场对一个长期现实方向的持续重新定价。

## 指数与产品的边界

Signa Index 本身是一套计算规则和连续点位，不是一份可以直接买卖的事件合约。

指数可以用来观察一个现实状态如何变化，也可以被其他产品引用，形成围绕该状态的正向或反向敞口。

因此，需要区分三个层次：

1. **事件合约**为具体结果定价；
2. **世界状态指数**聚合事件价格，描述长期状态；
3. **指数挂钩产品**为使用者提供相应的风险敞口。

## 正式定义

> 世界状态指数是一类以事件合约价格为定价基础，通过世界状态映射、方向统一、状态暴露加权与连续滚动，将多个离散事件合成为长期现实状态敞口的规则型合成指数。
