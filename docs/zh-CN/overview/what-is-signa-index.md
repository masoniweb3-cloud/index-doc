# 什么是 Signa Index？

<strong>Signa Index（世界状态指数，World-State Index）</strong>是一类以事件合约市场价格为定价基础，将多个离散事件映射到同一持续性现实状态，并通过方向统一、状态暴露加权与滚动接续构成的规则型合成指数。

它所表征的不是某一个事件，而是多个事件共同揭示的**世界状态因子**。这些状态包括国家发展、地缘秩序、政治权力和技术演进等跨越单一事件生命周期、持续变化的现实方向。

## 从事件价格到状态价格

预测市场中的每份合约都围绕一个有限命题，例如一次选举、一次政策决定或一项技术里程碑。合约价格表达市场对该命题结果的实时判断。

但现实中的重要方向很少由一个事件决定。和平进程、国家竞争力或技术扩散，都会通过一系列不同时间、不同形式的事件逐步显现。Signa Index 将这些局部信号组织起来，提取它们共同指向的状态变化。

## 指数与产品的边界

Signa Index 本身是规则化计算的金融基准，而不是某一份事件合约。它提供统一定义和连续点位；以指数点位或收益为结算依据，可以进一步构造指数挂钩产品。

因此，需要区分三个层次：

1. **事件合约**为具体结果定价；
2. **世界状态指数**聚合事件价格，描述长期状态；
3. **指数挂钩产品**为使用者提供相应的风险敞口。

## 一句话定义

> 世界状态指数是一类以事件合约价格为定价基础，通过世界状态映射、方向统一、状态暴露加权与连续滚动，将多个离散事件合成为长期现实状态敞口的规则型合成指数。
