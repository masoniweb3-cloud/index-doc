# 什么是 Signa Index？

**Signa Index 把多个围绕同一现实主题的预测市场，合成为一条持续更新的指数。**

比如，要判断一个地区的和平进程是在改善还是恶化，只看“是否会签署停火协议”这一份预测市场并不够。谈判是否重启、军事行动是否升级、制裁是否解除、第三方调解是否取得进展，都会影响和平进程。

这些事件各自回答一个具体问题。Signa Index 将它们放到同一个方向上，形成一条能够持续反映和平进程变化的指数。

如果股票指数用多家公司的股价描述一组公司的整体表现，那么 Signa Index 用多个事件合约的价格，描述一个现实状态的整体变化。

## 什么是“世界状态”？

世界状态，是无法由一个事件完整描述、但会被一系列事件共同推动的长期现实方向。例如：

- 一个国家的发展势能是在增强还是减弱；
- 一个地区的地缘局势是在缓和还是恶化；
- 一项技术是在加速普及还是失去动力；
- 一个政治力量是在扩大还是收缩。

单个事件会发生、结束和结算，但这些状态仍会继续变化。

## Signa 怎么把事件变成指数？

Signa 会完成四件事：

1. 找出真正会影响目标状态的事件；
2. 判断事件结果代表状态增强还是减弱；
3. 根据事件的重要性和市场质量分配权重；
4. 在旧事件结束后接入新事件，保持指数连续。

因此，Signa Index 不是事件概率的简单平均，而是市场对一个长期现实方向的持续重新定价。

## 你看到的“指数”和买到的“份额”有什么区别？

在 Signa 中，需要区分三个层次：

1. **事件合约**：预测市场中的具体问题，为某个结果形成市场价格；
2. **Signa 指数**：聚合多份事件合约，持续计算一个现实主题的正向或反向点位；
3. **指数份额**：Signa 根据指数点位提供报价、记录在用户账户中的交易持仓。

用户买卖的是第三层的指数份额，不是直接买入某一份预测市场合约。指数份额也不是发送到钱包里的 BEP-20 代币，目前不能转给其他用户或直接从链上提现。退出持仓时，需要先把份额卖出换回 USDT，再将可用 USDT 提现到登录钱包。

指数点位本身不是概率，也不是天然以 USDT 计价的代币价格。实际可以买到多少份、卖出可获得多少 USDT，以产品在报价有效期内给出的确认结果为准。

## 正式定义

> 世界状态指数是一类以事件合约价格为定价基础，通过世界状态映射、方向统一、状态暴露加权与连续滚动，将多个离散事件合成为长期现实状态敞口的规则型合成指数。
