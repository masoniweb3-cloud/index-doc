# Glossary

## World State

A persistent real-world direction revealed jointly by multiple events and extending beyond any single event's life.

## World-State Index

A rules-based synthetic index that combines discrete events into long-term state exposure through mapping, direction alignment, exposure weighting, and continuous rolling.

## Event Contract

A contract around a defined real-world proposition with observable market prices and settlement under specified outcomes.

## Target State

The persistent real-world direction measured by one index and the common coordinate for every component's direction and exposure.

## State Direction

A standardized representation of whether an event outcome strengthens or weakens the target state.

## State Exposure

The effective degree to which an outcome affects the target state, considering causal strength, information independence, and price quality.

## World-State Mapping

The process of normalizing natural-language events and establishing directional and causal relationships between outcomes and a target state.

## Rolling Continuity

Updating the component set after contracts expire or become invalid while continuing calculation from the existing index level.

## Index Share

A trading position quoted by Signa from a reference index level and recorded in the user's account. It is not an on-chain token sent to the wallet, is not currently transferable between users, and must be sold back into USDT before exit.
