# Signa Index Docs

Documentation for the Signa World-State Index methodology and index system.

English is the default documentation locale. Simplified Chinese content is authored first under `docs/zh-CN/`, then translated into the matching English paths after review.

## Local development

```bash
npm install
npm run docs:dev
```

## Content status

- Simplified Chinese: active authoring language
- English: structure reserved; translation begins after Chinese review
